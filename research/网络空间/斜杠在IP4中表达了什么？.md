# 斜杠在IP4中表达了什么？

你没见过它很正常，因为我们在手机或电脑上通常看到的 IP 地址（比如 `192.168.1.5`）是**单个设备**的地址，而 `192.168.1.0/24` 代表的是**一整个网络（一个网段）**。

  

通俗地打个比方：

  

- **`192.168.1.0/24`** 就像是“和平路”（整条街道的名字）。
    
      
    
- **`192.168.1.5`** 就像是“和平路 5 号”（街道上具体的一栋房子）。
    
      
    

平常我们配置路由器或者设置防火墙时，为了省事，不可能把家里的手机、电脑、电视的 IP 一个一个输进去，所以就会用 `192.168.1.0/24` 这一行代码，把它们**全部打包概括**。

  

### 这个格式具体是什么意思？

我们可以把它拆成两部分来看：

  

**1. 前面的 `192.168.1.0`**

这是这个网络的“网络编号”**。注意，以 `.0` 结尾的 IP 通常是一个网段的名称，它是**不能分配给任何一台具体的电脑或手机的。

  

**2. 后面的 `/24`**

这叫“子网掩码”（CIDR表示法）。它的意思是：这个 IP 地址的前 24 位（也就是前 3 个数字 `192.168.1`）是**固定死**的，只有最后一个数字可以变。

  

### 这个网段里到底包含了哪些 IP？

因为最后一个数字可以从 0 变到 255，所以 `192.168.1.0/24` 实际上包含了 **256** 个 IP 地址。它们的具体分工如下：

  

|**地址类型**|**具体地址 / 范围**|**它的作用**|
|---|---|---|
|**网络地址**|`192.168.1.0`|整个网段的“名字”，**不能**分配给设备。|
|**可用设备地址**|`192.168.1.1` 到 `192.168.1.254`|这些是可以分配给你家路由器、手机、电脑的地址（共 254 个）。|
|**广播地址**|`192.168.1.255`|相当于这个街道的“大喇叭”。往这个地址发消息，网段内所有设备都能收到，也**不能**分配给设备。|

**总结一下：**

当你看到 `192.168.1.0/24` 时，它的潜台词就是：“**从 `192.168.1.1` 到 `192.168.1.254` 的所有设备，都归我管。**”



当年搞网络开发的那帮工程师，为了**偷懒和高效**，硬是发明了这种把几万甚至几百万个 IP“打包”在一起的写法（专业术语叫 CIDR）。

  

要看懂这些例子，你只需要记住一个“减法法则”：**一个 IP 地址在电脑底层，固定只有 32 个位置（32位）。**

斜杠 `/` 后面的数字，代表“前面有多少个位置被锁死，不准动”。剩下的位置，就是能自由分配的 IP 数量。

  

比如 `/24` 就是锁死了前 24 个位置，剩下 8 个位置自由发挥（$2^8 = 256$ 个 IP）。

  

我给你看几个更猛的例子，你会发现**斜杠后面的数字越小，包含的 IP 就越多**：

  

### 1. “大厂园区”级别：`/16`

如果你看到 **`192.168.0.0/16`** （或者 `172.16.0.0/16`）：

  

- **意思是：** 只锁死前两个数字（192.168），后面两个数字随便变。
    
      
    
- **包含的 IP 范围：** 从 `192.168.0.1` 一直数到 `192.168.255.254`。
    
      
    
- **可用 IP 数量：** **65,534 个**！
    
      
    
- **使用场景：** 像南瑞这样的大型集团、大学校园网，员工和设备多，就会用这种网段，保证几万台设备连同一个 Wi-Fi 不会卡壳。
    
      
    

### 2. “跨国巨头 / 城市”级别：`/8`

如果你看到 **`10.0.0.0/8`**：

  

- **意思是：** 只锁死第一个数字（10），后面三个数字随便变。
    
      
    
- **包含的 IP 范围：** 从 `10.0.0.1` 狂飙到 `10.255.255.254`。
    
      
    
- **可用 IP 数量：** 将近 **1677 万个**！
    
      
    
- **使用场景：** 阿里云、腾讯云这种顶级机房，或者跨国公司的全球内网。一串短短的代码 `10.0.0.0/8`，就直接概括了 1600 多万台设备。
    
      
    

### 3. “极限抠门 / 二人世界”级别：`/30`

如果斜杠后面的数字变大，比如 **`192.168.1.0/30`**：

  

- **意思是：** 锁死了前 30 个位置，只剩 2 个位置（$2^2 = 4$）能动。
    
      
    
- **包含的 IP 范围：** 只有 `192.168.1.1` 和 `192.168.1.2` 能分给设备用。
    
      
    
- **可用 IP 数量：** **只有 2 个**。
    
      
    
- **使用场景：** 专门给两台核心路由器牵一根网线“私聊”用的，绝不浪费多余的 IP，多一台设备都连不进来。
    
      
    

> **为什么非要搞这么复杂？**
> 
> 想象一下，你作为网络管理员，要给公司防火墙拉黑一个恶意的黑客网段（里面有6万台电脑）。如果没有这个功能，你要把这 6 万个 IP 手动敲进去；但有了这个功能，你只需要敲一行 `黑名单：192.168.0.0/16`，这 6 万台电脑就瞬间被集体封杀了。这就是它的威力！
