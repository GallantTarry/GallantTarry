# 热门语言英文单词汇总
### ☕ 1. Java (面向对象、企业级与桌面开发)

Java 的生态庞大且严谨，这里的词汇多与面向对象设计（OOP）、工程化构建以及底层运行机制相关。

- **JVM (Java Virtual Machine)** - Java 虚拟机（跨平台的核心）
    
- **JRE (Java Runtime Environment)** - Java 运行环境（打包绿色版软件必带）
    
- **JDK (Java Development Kit)** - Java 开发工具包
    
- **Garbage Collection (GC)** - 垃圾回收机制
    
- **Polymorphism** - 多态
    
- **Encapsulation** - 封装
    
- **Serialization / Deserialization** - 序列化 / 反序列化（保存游戏进度或对象状态时常用）
    
- **Concurrency / Thread** - 并发 / 线程
    
- **Swing / AWT** - 桌面 GUI 图形工具包
    
- **Maven / Gradle** - 自动化构建工具
    
- **POM (Project Object Model)** - 项目对象模型（Maven 的核心配置文件）
    
- **Classpath** - 类路径（存放 `.class` 字节码文件的地方）
    
- **Annotation** - 注解（如 `@Override`）
    
- **Generics** - 泛型（如 `List<String>`）
    
- **Singleton** - 单例模式
    

### 🐍 2. Python (脚本、数据处理与 AI 生态)

Python 以简洁和高效著称，其高频词汇多集中在灵活的数据结构、简洁的语法糖以及数据处理领域。

- **Indentation** - 缩进（Python 区分代码块的灵魂）
    
- **Tuple** - 元组（不可变的数组）
    
- **Dictionary (Dict)** - 字典（键值对映射）
    
- **Slice** - 切片（快速提取列表中的一部分）
    
- **Decorator** - 装饰器（用 `@` 包装函数，增加额外功能）
    
- **Generator / Yield** - 生成器 / 产出（处理海量数据时不卡内存的神器）
    
- **Comprehension** - 推导式（如列表推导式 List Comprehension）
    
- **Virtual Environment (venv)** - 虚拟环境（隔离不同项目的依赖包）
    
- **Dataframe** - 数据框（Pandas 库中最核心的二维表格数据结构）
    
- **Scrape / Crawler** - 抓取 / 爬虫
    
- **Tensor** - 张量（深度学习框架中的基础多维数组）
    
- **Lambda** - 匿名函数
    
- **Interpreter** - 解释器
    

### ⚙️ 3. C / C++ (底层、内存与高性能)

C/C++ 是与操作系统、硬件底层以及高性能计算（如游戏引擎）打交道的利器，词汇十分硬核。

- **Pointer** - 指针（直接操作内存地址）
    
- **Address** - 内存地址（通常用 `&` 获取）
    
- **Dereference** - 解引用（通过指针获取对应内存里的值，通常用 `*`）
    
- **Memory Allocation (Malloc/Free)** - 动态内存分配与释放
    
- **Segmentation Fault (Segfault)** - 段错误（极其常见的报错：指针越界或访问非法内存）
    
- **Buffer Overflow** - 缓冲区溢出
    
- **Struct / Union** - 结构体 / 联合体（自定义复合数据类型）
    
- **Header File (.h)** - 头文件（存放声明）
    
- **Macro / Preprocessor** - 宏 / 预处理器（如 `#define`）
    
- **Compiler (GCC/Clang)** - 编译器
    
- **Linker** - 链接器（将目标文件打包成最终的 `.exe` 可执行文件）
    
- **Bitwise** - 按位操作（底层性能优化的常用手段）
    
- **Cast** - 类型转换（如强制类型转换）
    

### 🌐 4. 大前端 (HTML/CSS/JS & 热门框架)

前端领域的词汇迭代极快，主要围绕着页面结构、样式美化、异步逻辑以及现代组件化开发。

**基础与 DOM 操作：**

- **DOM (Document Object Model)** - 文档对象模型（网页的树状结构）
    
- **Element / Tag** - 元素 / 标签（如 `<div>`）
    
- **Attribute / Property** - 属性（HTML 标签上的自带配置）
    
- **Event Delegation** - 事件委托
    
- **Selector** - 选择器（CSS 和 JS 查找元素的规则）
    

**样式与排版 (CSS)：**

- **Flexbox** - 弹性盒子布局
    
- **Grid** - 网格布局
    
- **Responsive** - 响应式设计（适配手机和电脑屏幕）
    
- **Padding / Margin** - 内边距 / 外边距
    
- **Hover / Focus** - 悬停 / 聚焦（交互伪类）
    

**逻辑与异步 (JavaScript / Node.js)：**

- **Promise** - 承诺（处理异步操作的现代方法）
    
- **Async / Await** - 异步等待语法糖
    
- **Callback** - 回调函数
    
- **Event Loop** - 事件循环（JS 引擎处理任务的核心机制）
    
- **NPM (Node Package Manager)** - Node 包管理器
    

**现代框架 (React / Vue)：**

- **Component** - 组件
    
- **State** - 状态（组件内部可变的数据）
    
- **Props (Properties)** - 属性（父组件传给子组件的数据）
    
- **Lifecycle** - 生命周期（组件从创建到销毁的过程）
    
- **Hook** - 钩子函数（如 React 的 `useState` 或 Vue 的 `onMounted`）
    
- **Virtual DOM** - 虚拟 DOM（提升页面渲染性能的机制）
    
- **Routing / Router** - 路由（控制页面跳转逻辑）
