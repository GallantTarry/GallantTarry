# 编程世界 200 个高频与硬核核心英文单词汇总

### 1. 基础动作与操作 (CRUD & Actions)

这组词是所有增删改查和程序运行的基础。

1. **Create** - 创建
    
2. **Read** - 读取
    
3. **Update** - 更新
    
4. **Delete** - 删除
    
5. **Add** - 添加
    
6. **Remove** - 移除（通常指从集合中移出）
    
7. **Insert** - 插入
    
8. **Get** - 获取（最常用的 Getter 方法前缀）
    
9. **Set** - 设置（最常用的 Setter 方法前缀）
    
10. **Initialize** (init) - 初始化
    
11. **Execute** (exec) - 执行
    
12. **Compile** - 编译
    
13. **Build** - 构建
    
14. **Run** - 运行
    
15. **Stop** - 停止
    
16. **Pause** - 暂停
    
17. **Resume** - 恢复
    
18. **Parse** - 解析（如解析 JSON）
    
19. **Format** - 格式化
    
20. **Clear** - 清除
    

### 2. 数据与变量 (Data & Variables)

定义数据结构时天天打交道的词汇。

21. **String** - 字符串
    
22. **Integer** (int) - 整数
    
23. **Boolean** (bool) - 布尔值 (真/假)
    
24. **Float** - 单精度浮点数
    
25. **Double** - 双精度浮点数
    
26. **Array** - 数组
    
27. **List** - 列表
    
28. **Map / Dictionary** (dict) - 映射 / 字典
    
29. **Object** (obj) - 对象
    
30. **Class** - 类
    
31. **Variable** (var) - 变量
    
32. **Constant** (const) - 常量
    
33. **Parameter** (param) - 参数（定义函数时）
    
34. **Argument** (arg) - 实际参数（调用函数时传的值）
    
35. **Null** - 空（无对象）
    
36. **Undefined** - 未定义
    
37. **True** - 真
    
38. **False** - 假
    
39. **Index** - 索引
    
40. **Key-Value** - 键值对
    

### 3. 控制流与逻辑 (Control Flow & Logic)

控制程序走向的骨架。

41. **If** - 如果
    
42. **Else** - 否则
    
43. **Switch** - 分支切换
    
44. **Case** - 具体情况 / 案例
    
45. **For** - 循环（计次）
    
46. **While** - 循环（条件）
    
47. **Do** - 执行
    
48. **Break** - 中断 / 跳出当前循环
    
49. **Continue** - 继续 / 跳过本次循环
    
50. **Return** - 返回（函数结果）
    
51. **Try** - 尝试（异常处理）
    
52. **Catch** - 捕获（异常）
    
53. **Finally** - 最终（无论是否异常都会执行）
    
54. **Throw** - 抛出（异常）
    
55. **Exception** - 异常
    

### 4. 面向对象与架构 (OOP & Architecture)

你在写 Spring Boot 项目或进行类设计时最关键的修饰词。

56. **Function** (func) - 函数
    
57. **Method** - 方法（属于对象的函数）
    
58. **Interface** - 接口
    
59. **Abstract** - 抽象的
    
60. **Implement** (impl) - 实现
    
61. **Extend** - 继承 / 扩展
    
62. **Override** - 重写 / 覆盖
    
63. **Overload** - 重载
    
64. **Public** - 公开的
    
65. **Private** - 私有的
    
66. **Protected** - 受保护的
    
67. **Static** - 静态的
    
68. **Final** - 最终的 / 不可变的
    
69. **Package** - 包
    
70. **Module** - 模块
    

### 5. 版本控制与协作 (Git / GitHub / Gitee)

日常提代码、合 PR 必备。

71. **Repository** (Repo) - 仓库
    
72. **Branch** - 分支
    
73. **Commit** - 提交
    
74. **Push** - 推送（到远程）
    
75. **Pull** - 拉取（到本地）
    
76. **Fetch** - 获取（更新状态但不合并）
    
77. **Merge** - 合并
    
78. **Clone** - 克隆
    
79. **Conflict** - 冲突
    
80. **Request** - 请求 (如 Pull Request)
    
81. **Review** - 代码审查
    
82. **Issue** - 议题 / 缺陷跟踪
    
83. **Tag** - 标签 / 版本号
    
84. **Revert** - 还原 / 撤销
    
85. **Ignore** - 忽略 (如 .gitignore)
    

### 6. 网络通信与数据库 (Network & DB)

前后端交互与数据持久化的核心概念。

86. **Query** - 查询
    
87. **Response** - 响应
    
88. **Header** - 请求头
    
89. **Body** - 请求体
    
90. **Payload** - 有效载荷（实际传输的数据）
    
91. **Token** - 令牌（身份验证）
    
92. **Session** - 会话
    
93. **Cache** - 缓存
    
94. **Table** - 数据表
    
95. **Row** - 行（记录）
    
96. **Column** - 列（字段）
    
97. **Primary** - 主键的 (Primary Key)
    
98. **Foreign** - 外键的 (Foreign Key)
    
99. **Connect** - 连接
    
100. **Disconnect** - 断开连接
    

### 7. 人工智能与大模型 (AI & Agent Technologies)

现在跟各类 API 和大模型打交道，这些词是高频中的高频。

101. **Agent** - 智能体（能自主执行任务的 AI）
    
102. **Prompt** - 提示词
    
103. **Context** - 上下文（给 AI 提供的前提信息）
    
104. **Embedding** - 词嵌入 / 向量化（把文字转为机器能懂的数字）
    
105. **Vector** - 向量（向量数据库查询的核心）
    
106. **Dataset** - 数据集
    
107. **Fine-tune** - 微调（用特定数据训练大模型）
    
108. **Inference** - 推理（模型生成答案的过程）
    
109. **Latency** - 延迟（API 响应的等待时间）
    
110. **Model** - 模型
    
111. **Train** - 训练
    
112. **Neural** - 神经网络的
    
113. **Weight** - 权重
    
114. **Bias** - 偏置
    
115. **Token** - 词元（大模型计费和文本长度的单位）
    
116. **Vision** - 视觉（如识别图像的机器视觉）
    
117. **Hallucination** - 幻觉（AI 一本正经地胡说八道）
    
118. **Predict** - 预测
    
119. **Generate** - 生成
    
120. **Pipeline** - 流水线 / 管道（数据处理的完整流程）
    

### 8. 桌面 UI 与架构解耦 (GUI & Architecture)

当你在重构复杂的桌面工具箱、处理多面板（Panel）交互、或者给界面换上暗黑主题时，这些词就是你的骨架。

121. **Component** - 组件（独立的功能块）
    
122. **Panel** - 面板（UI 布局的基础块）
    
123. **Layout** - 布局
    
124. **Theme** - 主题
    
125. **Event** - 事件（如点击、拖拽）
    
126. **Listener** - 监听器（捕获事件的代码）
    
127. **Render** - 渲染（将代码转化为可见的图形，注意是否开启硬件加速）
    
128. **Thread** - 线程（耗时任务必须放后台线程，以免卡死 UI）
    
129. **Async (Asynchronous)** - 异步
    
130. **Sync (Synchronous)** - 同步
    
131. **Lock** - 锁（比如防止应用多开的 File-locking 机制）
    
132. **Instance** - 实例
    
133. **Decouple** - 解耦（把揉在一起的代码拆分成独立模块）
    
134. **Refactor** - 重构（不改变功能的前提下优化代码结构）
    
135. **Plugin** - 插件
    
136. **Widget** - 小部件
    
137. **Dialog** - 对话框
    
138. **Canvas** - 画布（自定义绘图区域）
    
139. **Container** - 容器
    
140. **Scroll** - 滚动
    

### 9. 数据清洗与脚本处理 (Data Processing & Scripting)

用 Python 搞自动化，跨工作簿去清洗、对比和匹配格式不一致的数据，或者解析一大串 JSON 地理编码时，这些词你天天见。

141. **Cleanse / Clean** - 清洗（处理脏数据）
    
142. **Extract** - 提取
    
143. **Match** - 匹配（比如跨表的单元格行对齐）
    
144. **Sort** - 排序
    
145. **Filter** - 过滤
    
146. **Regex (Regular Expression)** - 正则表达式（提取复杂字符串的神器）
    
147. **Split** - 分割（将一串地址或字符拆成数组）
    
148. **Concatenate (Concat)** - 拼接
    
149. **Pattern** - 模式（设计模式，或者字符串匹配规则）
    
150. **Buffer** - 缓冲区
    
151. **Stream** - 数据流
    
152. **Node** - 节点（解析 JSON 或 XML 树的层级结构）
    
153. **Tree** - 树状结构
    
154. **Mapping** - 映射（比如实体模型到数据库表的关联）
    
155. **Config (Configuration)** - 配置
    
156. **Annotation** - 注解 / 注释（给代码加上的元数据标注）
    
157. **Validate** - 验证（如检查缓存机制是否有效）
    
158. **Scale** - 缩放 / 扩展
    
159. **Geocode** - 地理编码（处理地址与行政区划的转换）
    
160. **Proxy** - 代理（处理网络连接限制）
    

### 10. 独立游戏与引擎逻辑 (Game Dev & Graphics)

当你从业务代码切换到开发像素生存类游戏，调整游戏节奏和平衡性时，思维模式要切换到这一组。

161. **Sprite** - 精灵图（2D 游戏里的人物或物品图像）
    
162. **Asset** - 资产（你的图像素材、音频目录）
    
163. **Texture** - 纹理
    
164. **Physics** - 物理（处理游戏世界的物理法则）
    
165. **Collision** - 碰撞
    
166. **Gravity** - 重力
    
167. **Velocity** - 速度（带方向的移动向量）
    
168. **Spawn** - 生成 / 衍生（比如在地图上刷怪）
    
169. **Loop** - 循环（游戏的主循环，或者复古 8-bit 音效的无缝循环）
    
170. **Frame** - 帧
    
171. **FPS (Frames Per Second)** - 帧率
    
172. **Scene** - 场景
    
173. **Camera** - 摄像机（玩家屏幕看到的区域）
    
174. **State** - 状态（角色的生死、移动状态）
    
175. **Collider** - 碰撞体（包裹在角色外面的无形边界）
    
176. **Tile** - 瓦片（拼接游戏地图的基础地砖）
    
177. **Coordinate** - 坐标
    
178. **Logic** - 逻辑
    
179. **Balance** - 平衡（反复调试数值，让游戏好玩）
    
180. **Survival** - 生存
    

### 11. 进阶开源协作与自动化部署 (GitHub Advanced & DevOps)

平时维护自己的代码库、在 GitHub Pages 挂载静态网页或是设置构建流水线时，这些词决定了你的代码如何走向世界。

181. **Deploy** - 部署
    
182. **Release** - 发布版本
    
183. **Environment** - 环境（开发环境、测试环境、生产环境）
    
184. **Dependency** - 依赖（比如配置里那一大串的引入库）
    
185. **Registry** - 注册表 / 注册中心
    
186. **Artifact** - 构建产物（编译打包后生成的最终文件）
    
187. **Script** - 脚本
    
188. **Automate** - 自动化
    
189. **Snippet** - 代码片段
    
190. **Upstream** - 上游（开源项目主仓库）
    
191. **Downstream** - 下游
    
192. **Resolve** - 解决（通常伴随着令人头疼的解决冲突 Resolve Conflict）
    
193. **Patch** - 补丁
    
194. **Maintainer** - 维护者
    
195. **Milestone** - 里程碑（版本规划）
    
196. **Hook** - 钩子（在特定事件发生时自动触发的代码，如 Git hook）
    
197. **Trigger** - 触发器
    
198. **Action** - 动作流（如 GitHub Actions）
    
199. **Fork** - 派生（复制大佬的项目到自己的名下）
    
200. **Star** - 星标（开源世界里的点赞）
    

> **修炼小建议：** 不要把这 200 个词当纯粹的英语单词去背，试着把它们当成构建软件的**乐高积木**。下次给你的代理助手写新功能，或是重构桌面应用代码时，试着在脑海里直接用这些英文词汇去构建逻辑链路，你的代码语感自然会大幅提升。
