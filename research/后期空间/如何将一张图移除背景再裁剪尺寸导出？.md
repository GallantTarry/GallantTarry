# 如何将一张图移除背景再裁剪尺寸导出？



“抠出图标 ➔ 裁掉周围多余的空白 ➔ 缩放/输出成规定的精确尺寸”。

  

这是一个非常标准的图标处理工作流。为了确保图标完美居中、没有多余的透明边框，并且尺寸精准，你可以按照以下最规范的步骤操作：

  

### 第一步：清除背景（把底色变成透明）

如果你打开的 PNG 或 JPG 图标带有白色或其他纯色背景，需要先把它抠出来：

  

1. **解锁图层：** 在右侧“图层”面板中，双击图层名字旁边的小锁头，将其解锁（变成“图层0”）。
    
      
    
2. **删除背景：**
    
      
    - **如果你的 PS 是较新版本（2020 及以上）：** 在“属性”面板中，直接点击快速操作里的 **“移除背景”（Remove Background）**，PS 会用 AI 自动抠图。
        
          
        
    - **如果是老版本或纯色背景：** 在左侧工具栏选择 **“魔棒工具”（快捷键 W）**，点击背景的颜色，然后按下键盘的 **Delete** 键删掉背景。此时背景会变成灰白相间的格子（代表透明）。
        
          
        

### 第二步：一键自动贴边裁切（仅保留图标主体）

不要用手动裁剪工具去估算边缘，PS 有一个自动贴边裁切的神器：

  

1. 点击顶部菜单栏的 **图像 (Image) > 裁切 (Trim...)**。
    
      
    
2. 在弹出的窗口中，选择最上方的 **“透明像素”（Transparent Pixels）**。
    
      
    
3. 确保下方的“顶、底、左、右”四个框都勾选，点击确定。
    
      
    

> **结果：** 此时画布会自动“缩水”收紧，完美贴合你图标的边缘，一丁点多余的空白都不会留。
> 
>   

### 第三步：调整为想要的尺寸并导出

现在图标已经没有多余边缘了，接下来调整为你想要的最终尺寸。这里分两种情况：

  

**情况 A：你只想把这个图标本身缩放成某个尺寸（比如图标本身就是 500x500）**

  

1. 按 `Ctrl + Alt + I`（Mac: `Cmd + Option + I`）打开 **图像大小**。
    
      
    
2. 输入你想要的宽度或高度（注意勾选那个锁链图标保持比例，以免图标被拉变形），点击确定。
    
      
    
3. 按 `Ctrl + Shift + Alt + W`（或点击 文件 > 导出 > 导出为），选择 **PNG** 格式，勾选“透明度”，直接导出即可。
    
      
    

**情况 B：你需要一个固定大小的正方形画布（比如 256x256），而图标在正中间**

_这是做 UI 和系统图标最常见的需求，图标本身可能不是正方形的。_

  

1. 点击顶部菜单栏 **文件 (File) > 导出 > 导出为 (Export As...)**。
    
      
    
2. 在右侧面板中，格式选择 **PNG**，勾选 **“透明度”**。
    
      
    
3. 往下看，找到 **“画布大小”（Canvas Size）** 这一栏。
    
      
    
4. 在这里输入你想要的最终文件尺寸（比如 宽 256，高 256）。
    
      
    

> **结果：** PS 会自动把你刚才紧凑的图标放在一个 256x256 的透明正方形正中间。你可以直接点击导出，大功告成！
> 
>   

**总结这个神仙连招就是：** 抠图删背景 ➔ 图像>裁切(透明像素) ➔ 导出为>设置画布大小。这样导出的图标最规范。
