# 请问script style link 都是什么？

在网页制作和前端开发的世界里，`<script>`、`<style>` 和 `<link>` 是最基础、最核心的三大 HTML 标签。它们各司其职，分别负责控制网页的**行为逻辑**、**外观样式**以及**外部资源的引入**。

  

我们可以用造房子来打个比方：HTML 是钢筋水泥骨架，这三个标签就是给毛坯房通电、刷漆和运建材的工具。

  

### 1. `<script>` 标签 —— 网页的“大脑与行为”

- **它是干什么的**：用来加载或编写 **JavaScript（JS）** 代码。JavaScript 是一种编程语言，负责赋予网页交互能力和动态逻辑。
    
      
    
- **常见用途**：
    
      
    - 响应用户的点击、输入和滑动（比如你网站里点击菜单切换面板）。
        
          
        
    - 处理数据、控制动画（比如小电视跳舞、粒子特效）。
        
          
        
    - 像你刚刚操作的那样，引入外部的 JS 库（如 Vue.js、Tailwind 引擎）。
        
          
        
- **代码示例**：
    
      
    
    HTML
    
    ```
    <!-- 引入外部 JS 文件 -->
    <script src="./js/vue.global.js"></script>
    
    <!-- 或者直接在标签内写 JS 代码 -->
    <script>
        console.log("少侠好！");
    </script>
    ```
    

### 2. `<style>` 标签 —— 网页的“内部化妆师”

- **它是干什么的**：用来直接在 HTML 页面内部编写 **CSS（层叠样式表）** 代码。CSS 负责控制网页长什么样（颜色、字体、排版、大小、动画等）。
    
      
    
- **特点**：通常写在 `<head>` 标签里，它里面的样式**只对当前的这一个 HTML 网页生效**。
    
      
    
- **常见用途**：写一些当前页面专属的自定义样式（比如你页面里那些复杂的毛玻璃效果 `.glass-panel` 或扫描线 `.scanlines`）。
    
      
    
- **代码示例**：
    
      
    
    HTML
    
    ```
    <style>
        body {
            background-color: #050505; /* 让整个页面背景变成炫酷的纯黑 */
            color: #f8fafc;
        }
    </style>
    ```
    

### 3. `<link>` 标签 —— 网页的“外部资源引桥”

- **它是干什么的**：用来在当前网页中**链接外部的资源文件**（最常用的是引入外部的 CSS 样式表文件或网页图标）。
    
      
    
- **特点**：它是一个**自闭合标签**（不需要写 `</link>`）。它通过 `rel` 属性来告诉浏览器：“我要链接的是个什么东西”。
    
      
    
- **常见用途**：
    
      
    - 引入外部的 `.css` 样式文件。
        
          
        
    - 引入网站的标签页小图标（Favicon，正如你代码里写的那样）。
        
          
        
    - 引入外部的字体文件。
        
          
        
- **代码示例**：
    
      
    
    HTML
    
    ```
    <!-- 1. 引入外部的 CSS 样式表 -->
    <link rel="stylesheet" href="style.css">
    
    <!-- 2. 引入网页标签页的图标 -->
    <link href="imgs/favicon.png" rel="icon" type="image/png">
    ```
    

### 💡 核心区别总结表

|**标签**|**核心核心职责**|**控制对象**|**是否需要成对出现 (</...>)**|
|---|---|---|---|
|**`<script>`**|行为与逻辑|JavaScript 脚本|**是**|
|**`<style>`**|内部样式美化|CSS 样式代码（写在页面内部）|**是**|
|**`<link>`**|外部资源桥梁|外部文件（如 CSS、图标、字体）|**否**（单标签）|

搞懂这三个标签，你基本上就看懂了所有网页最核心的“穿衣打扮和思考逻辑”了！
