
# Markdown 语法如何使用？

## 第一篇：环境准备 —— 如何绑定新建 Markdown

在 Windows 系统下快速新建 Markdown（.md）文件有几种非常高效的方法，你可以根据当下的操作习惯来选择：

  

### 1. 终端命令行快速创建（极速版）

如果你习惯敲代码，可以直接呼出常用的 cmd 或 PowerShell 进行创建。

  

**在 cmd 中：**

  

DOS

```
type nul > 你的文件名.md
```

**在 PowerShell 中：**

  

PowerShell

```
New-Item 你的文件名.md
```

> _(如果你正好切到了你配置好的 WSL2 Ubuntu 环境里，那直接用老规矩敲 `touch 你的文件名.md` 就可以了。)_
> 
>   

### 2. 桌面右键菜单一键新建（一劳永逸版）

如果希望像新建文本文档一样，直接在桌面右键就能选择新建 Markdown 文件，可以通过一行命令将它加入右键列表：

  

1. 用管理员身份运行 cmd。
    
      
    
2. 复制并运行以下命令：
    
      
    

DOS

```
reg add "HKEY_CLASSES_ROOT\.md\ShellNew" /v NullFile /f
```

刷新一下桌面，以后在任何地方右键 -> 新建，就能直接看到 Markdown 文件的选项了，操作极其顺手。

  

### 3. 文本重命名法（最常规）

1. 在桌面或文件夹空白处 右键 -> 新建 -> 文本文档。
    
      
    
2. 直接将文件后缀名从 `.txt` 改为 `.md` 即可。
    
      
    

> _(注意：如果看不到后缀名，需要在资源管理器顶部的“查看”菜单中，勾选“文件扩展名”。)_
> 
>   

## 第二篇：基础实战 —— 如何使用 MarkDown 基本语法？

Obsidian 是一件非常趁手的知识管理兵器，它的语法大部分遵循标准 Markdown，同时也加入了一些极其强大的独占扩展（比如双链和标注）。这里为你系统梳理一下日常做笔记和沉淀技术文档最常用的排版语法：

  

### 1. 标题 (Headings)

在文字前加上 `#` 和一个空格，就可以创建标题。`#` 的数量代表标题的层级，最多支持六级。

  

Markdown

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 2. 文本格式 (Text Formatting)

Obsidian 支持标准的文本修饰，其中高亮是其非常实用的特色功能。

  

|**效果**|**语法示例**|
|---|---|
|**加粗**|`**文字**` 或 `**核心逻辑**`|
|_斜体_|`*文字*` 或 `*注意事项*`|
|~~删除线~~|`~~文字~~` 或 `~~废弃方案~~`|
|==高亮==|`==文字==` 或 `==重点标红==`|

### 3. 列表 (Lists)

列表可以互相嵌套，只需要在换行后按 `Tab` 键缩进即可。

  

- **无序列表**（使用 `-`、`*` 或 `+` 加空格）：
    
      
    
    Markdown
    
    ```
    - 第一项
    - 第二项
      - 子项 (按 Tab 缩进)
    ```
    
- **有序列表**（使用数字加英文句号和空格）：
    
      
    
    Markdown
    
    ```
    1. 第一步：初始化环境
    2. 第二步：配置依赖
    ```
    
- **任务列表 / Task Lists**（非常适合用来做待办事项追踪）：
    
      
    
    Markdown
    
    ```
    - [ ] 未完成的任务
    - [x] 已完成的任务
    ```
    

### 4. 代码块 (Code Blocks)

作为日常沉淀代码片段的工具，代码块必不可少。

  

- **行内代码**：使用反引号包裹，适合标记类名、方法名或短命令。键盘左上方波浪键。
    
    语法：`` `String` `` 效果：`String`
    
      
    
- **多行代码块**：使用三个反引号包围，并在第一行末尾指定编程语言（如 java, sql, bash 等）以实现语法高亮。
    
      
    
    Java
    
    ```
    @RestController
    @RequestMapping("/api")
    public class TestController {
        // 你的代码
    }
    ```
    

### 5. 引用与标注 (Quotes & Callouts)

- **普通引用**：在文字前加 `>`。
    
      
    
    > 放弃对“术”的沉迷，追求底层的“道”。
    > 
    >   
    
- **Obsidian 专属标注 (Callouts)**：这是 Obsidian 中极其美观的功能，可以在引用块中加上特定的标记来改变样式。支持的类型有很多，比如 `[!note]`, `[!warning]`, `[!info]`, `[!danger]` 等。
    
      
    
    Markdown
    
    ```
    > [!warning] 注意
    > 这里的数据库连接需要隔离，否则会报错。
    
    > [!tip] 提示
    > 可以使用快捷键 Cmd/Ctrl + E 快速切换编辑/阅读模式。
    ```
    

### 6. 链接 (Links)

- **双向链接 (Obsidian 的灵魂)**：使用双方括号，可以快速链接到你的其他笔记页面。
    
      
    
    Markdown
    
    ```
    [[另一篇笔记的名称]]
    [[笔记名称#某个特定的标题]]
    ```
    
- **外部链接**：链接到网上的网页。
    
      
    
    Markdown
    
    ```
    [链接显示的文字](https://www.example.com)
    ```
    

### 7. 分隔线 (Horizontal Rules)

连续输入三个或以上的 `-` 或 `*`，并独占一行，可以生成一条分割线，用来划分文档区块。

  

Markdown

```
---
```

💡 **快速上手建议：**

少侠可以直接将上面的语法复制到 Obsidian 的新建笔记里，然后按下 `Ctrl + E`（或点击右上角的一本书/笔的图标）在“阅读视图”和“编辑视图”之间切换，立刻就能直观地看到所有排版效果。

  

## 第三篇：底层原理 —— 代码块语法高亮背后的奥秘

简单来说，当你在 ` ``` `（代码块标记）的右边加上 `java` 时，你是在给解析 Markdown 的软件发送一个指令：“**请把这段文字当作 Java 代码来阅读和美化。**”

  

以下是它背后的具体工作原理：

  

### 1. Markdown 解析器的作用

Markdown 本身只是一种纯文本格式，但在你阅读它时（比如在网页、笔记软件或代码编辑器里），后台会有一个“解析引擎”把它转换成漂亮的网页样式（HTML + CSS）。

  

- 当你只输入 ` ``` ` 时，解析引擎只知道这块内容是代码。它会把文字放进一个灰色的框框里，并使用等宽字体，但**不会对文字上色**，因为系统不知道这是什么语言。
    
      
    
- 当你输入 ` ```java ` 时，解析引擎就会去调用内置的 **Java 词法分析器**。
    
      
    

### 2. 词法分析与上色

解析引擎知道这是 Java 代码后，就会按照 Java 的语法规则去“拆解”你的代码，并给不同类型的单词涂上不同的颜色（具体的颜色取决于你当前使用的软件主题）：

  

- **关键字（Keywords）**：比如 `public`, `class`, `void`, `if`, `for` 会被标记为一种颜色。
    
      
    
- **字符串（Strings）**：被双引号 `""` 包裹的内容，比如 `"Hello"`，会被标记为另一种颜色。
    
      
    
- **注释（Comments）**：以 `//` 或 `/* */` 开头的内容会变成灰色或绿色。
    
      
    
- **类名、方法名**：也会被专门识别出来。
    
      
    

### 3. 直观对比

我们可以通过下面的对比来看看区别：

  

**不加任何标识（只输入 ` ``` `）：**

  

Plaintext

```
public class Test {
    // 这是一个测试方法
    public static void main(String[] args) {
        String msg = "Hello Data Structures!";
        System.out.println(msg);
    }
}
```

**加上标识（输入 ` ```java `）：**

  

Java

```java
public class Test {
    // 这是一个测试方法
    public static void main(String[] args) {
        String msg = "Hello Data Structures!";
        System.out.println(msg);
    }
}
```

你会发现，加上 `java` 后，代码的结构层次瞬间变得极其清晰，非常便于阅读和排错。

  

### 4. 其他语言也通用

这个机制不仅限于 Java，世界上几乎所有主流的编程语言和标记语言都可以用这种方式高亮。例如：

  

- ` ```python ` (Python 代码)
    
      
    
- ` ```c ` (C 语言代码)
    
      
    
- ` ```html ` (网页 HTML 标签)
    
      
    
- ` ```json ` (JSON 数据格式)
    
      
    
- ` ```sql ` (数据库查询语句)
    
      
    

所以，在编写技术文档、做学习笔记或者跟别人交流代码时，养成在 ` ``` ` 后面加上对应语言名称的习惯，会让你的文档看起来极其专业且美观。
