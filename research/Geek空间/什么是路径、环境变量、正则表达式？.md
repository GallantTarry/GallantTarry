# 什么是路径、环境变量、正则表达式？

## 一、 路径 (Paths) —— 寻人的基础地图

这俩概念其实非常简单，咱们用最直白的说法一句话搞定：

- **绝对路径** = **完整的收货地址**（比如：某省某市某区某街道某号）。 不管你现在身在何处，只要照着这个地址找，就一定能找到目标。
    
- **相对路径** = **问路的指南**（比如：从这往前走两个路口，右拐）。 它完全取决于你**现在站在哪里**。
    

### 1. 绝对路径 (Absolute Path)

它是一条“走到底”的完整路线，**永远从最顶层的根目录开始写起**。

- **在 Windows 系统中**：总是以盘符（C盘、D盘）开头。
    
    - 例如：`C:\Users\Shaoxia\Desktop\秘籍.txt`
        
- **在 Mac / Linux 系统中**：总是以斜杠 `/`（根目录）开头。
    
    - 例如：`/home/shaoxia/documents/秘籍.txt`
        

**优点**：非常精准，无论你当前在电脑的哪个文件夹里操作，用绝对路径都不会出错。 **缺点**：太长了，如果把项目发给别人，别人的电脑可能没有 `C:\Users\Shaoxia\` 这个目录，代码就会报错。

### 2. 相对路径 (Relative Path)

它是一条“抄近道”的路线，**基于你当前所在的文件夹**来寻找目标。 这里有两个必须记住的“暗号”：

- `.` （单点）：代表**当前**所在的文件夹。
    
- `..` （双点）：代表**上一级**文件夹（也就是退出去一层）。
    

**举个实战例子，少侠请看：**

假设你现在正站在 `C:\Users\Shaoxia\Desktop` 这个文件夹里。

1. 你要找同在桌面上的 `秘籍.txt`。
    
    - 相对路径直接就是：`秘籍.txt` （或者 `./秘籍.txt`）
        
2. 你要找位于上一级文件夹（Shaoxia）里的 `照片.png`。
    
    - 相对路径就是：`..\照片.png` （意思是：退到上一级，找到照片）
        
3. 你要找上一级文件夹里，Downloads 文件夹中的 `武器.exe`。
    
    - 相对路径就是：`..\Downloads\武器.exe`
        

**优点**：简短灵活，非常适合写代码和做项目。 只要文件夹内部的结构不乱，整个项目文件夹打包发给别人也能正常运行。

**快速对比总结**

|**特性**|**绝对路径 (Absolute)**|**相对路径 (Relative)**|
|---|---|---|
|**起点**|根目录（如 `C:\` 或 `/`）|当前所在的文件夹|
|**长度**|通常很长|通常较短|
|**可移植性**|差（换台电脑可能就找不到）|极好（整个文件夹移动也不影响）|
|**适用场景**|寻找系统固定文件、下载保存路径|代码编写、网页开发、项目内部文件互相引用|

## 二、 环境变量与特殊符号 (%) —— 江湖代号与任意门

没问题，少侠！刚才的内功心法确实还差了两块重要的拼图。 如果你把“路径”当成寻人的地图，那么 `%` 就是“传送门”，而正则表达式（Regex）则是江湖上最顶级的“天网寻人令”。

咱们这就把这两招进阶心法补齐！

### `%` 的奥秘：江湖代号与任意门

在计算机世界里，`%` 主要在两个截然不同的场景下出场，少侠千万别弄混了：

#### 场景 A：Windows 路径里的“任意门”（环境变量）

在 Windows 系统的路径中，`%` 总是成对出现的（比如 `%USERPROFILE%`）。 它代表一个“动态的代号”。

- **痛点：** 你的电脑叫 `C:\Users\Shaoxia`，你朋友的电脑叫 `C:\Users\Daxia`。 如果你写死绝对路径，发给朋友就报错了。
    
- **破局：** 使用 `%USERPROFILE%\Desktop\秘籍.txt`。
    
- **效果：** 这是一个自动识别身份的任意门。 在你的电脑上，它会自动变身成 `Shaoxia` 的桌面；在你朋友电脑上，会自动变成 `Daxia` 的桌面。
    
- _常见的代号还有：_ `%APPDATA%`（软件配置文件夹）、`%TEMP%`（临时文件夹）。
    

少侠问得好！在 Windows 系统的江湖里，这三个带有 `%` 的词叫做“环境变量” (Environment Variables)。 你可以把它们理解为系统自带的“高级快捷传送门”。 因为每台电脑的用户名不一样（比如你的大本营叫 `C:\Users\Lei`，别人的叫 `C:\Users\Admin`），如果软件死记硬背绝对路径，换台电脑就找不到路了。 所以 Windows 发明了这些通用代号。

只要你在“文件资源管理器”的地址栏，或者按下 `Win + R` 调出“运行”窗口，输入它们并回车，就能瞬间传送到对应的隐藏领地：

**1. `%USERPROFILE%`：你的“大本营”**

- **它的真身：** 当前登录用户的个人主文件夹。
    
- **默认路径：** 通常是 `C:\Users\你的用户名`。
    
- **里面有什么：** 你的“桌面 (Desktop)”、“下载 (Downloads)”、“文档 (Documents)”、“图片”等个人专属文件夹全都在这里面。
    
- **应用场景：** 当一个软件想把文件保存到你的桌面上，它代码里写的就是 `%USERPROFILE%\Desktop`，这样不管谁在用这台电脑，文件都能准确落在当前用户的桌面上，绝不跑偏。
    

**2. `%APPDATA%`：软件的“绝密账本”**

- **它的真身：** 应用程序数据文件夹 (Application Data - Roaming)。 这是一个隐藏系统文件夹，平时你是看不见的。
    
- **默认路径：** 通常是 `C:\Users\你的用户名\AppData\Roaming`。
    
- **里面有什么：** 软件和游戏的**个人偏好设置、账号配置、游戏存档、聊天记录**。 比如你的代码编辑器配置、微信的本地数据、甚至很多单机游戏的存档，都会偷偷藏在这里。
    
- **应用场景：** 当你卸载并重新安装某个软件时，只要这个文件夹里的东西没删，你重新打开软件时会发现：登录状态还在，习惯的设置也都没变。
    

**3. `%TEMP%`：系统的“临时客栈”（也是垃圾桶）**

- **它的真身：** 临时文件夹 (Temporary folder)。
    
- **默认路径：** 通常是 `C:\Users\你的用户名\AppData\Local\Temp`。
    
- **里面有什么：** 软件在运行、解压文件或安装更新时，临时存放的“边角料”和缓存。
    
- **应用场景：** 比如你双击解压一个超大的压缩包，系统会先把它临时解压到这里，然后再移动到你指定的目录。
    
- **💡 实用秘籍：** 理论上，软件用完这些临时文件就该自己清理掉，但很多软件“不讲武德”用完就跑。 所以，如果少侠发现 C 盘快满了，可以直接进入 `%TEMP%` 文件夹，**把里面的东西全选删除来腾出空间**（遇到提示“正在被使用无法删除”的文件，直接点跳过即可，那说明当前正有软件在用它）。
    

少侠现在就可以试着按下键盘上的 `Win + R` 键，输入 `%TEMP%` 然后敲回车，亲自去这个“临时客栈”转转！

#### 场景 B：搜索与数据库中的“百变星君”（通配符）

在很多搜索框、命令行（尤其是 SQL 数据库查询）里，单打独斗的 `%` 代表“零个、一个或多个任意字符”。

- 比如你要找一本名字记不清的秘籍，只记得包含“九阳”两个字。
    
- 搜索指令写成：`%九阳%`
    
- 它能帮你找出：《**九阳**神功》、《真**九阳**传》、《新编**九阳**真经白话版》等所有匹配的目标。
    

## 三、 正则表达式 (Regex) —— 终极寻人启事

如果说绝对/相对路径是“精确找人”，那正则表达式（Regular Expression）就是“按特征抓人”。 它不关心文件具体在哪个文件夹，它只关心文本或文件名**长什么样**。

它有一套专门的“暗号体系”。 少侠请看最常用的几个基础暗号：

|**暗号符**|**招式名称**|**作用说明**|**实战举例**|
|---|---|---|---|
|`.`|**单体易容**|匹配**任意单个字符**（除了换行符）。|`秘籍.txt` 可以匹配 `秘籍1.txt`、`秘籍A.txt`，但不能匹配 `秘籍12.txt`。|
|`*`|**影分身术**|匹配前面的字符 **0次或多次**。|`哈*` 可以匹配（空）、`哈`、`哈哈`、`哈哈哈哈`。|
|`.*`|**万物皆空**|`.` 和 `*` 的组合，代表**任意长度的任意字符**。|`九阳.*真经` 可以匹配 `九阳神功真经`、`九阳真经`。|
|`[ ]`|**门派令牌**|匹配括号里的**任意一个**字符。 可以划定范围。|`[0-9]` 代表只匹配数字；`[a-zA-Z]` 代表只匹配英文字母。|
|`^`|**潜龙出水**|锁定必须以这个字符**开头**。|`^少侠` 只能匹配以“少侠”两个字开头的句子。|
|`$`|**神龙摆尾**|锁定必须以这个字符**结尾**。|`\.pdf$` 只能匹配以 `.pdf` 结尾的文件名。|

#### ⚔️ 实战演练：组合连招

假设少侠手里有一份长长的名单，你要用正则表达式把特定的目标揪出来：

1. **目标：** 找出所有 2026 年拍摄的 `.jpg` 格式的照片（假设命名规律是 `2026-月份-日期.jpg`）。
    
    - **正则连招：** `^2026-[0-9]{2}-[0-9]{2}\.jpg$`
        
    - **拆招解析：** `^2026-` 必须以此开头，`[0-9]{2}` 代表必须连续出现两个数字（月份和日期），`\.jpg$` 必须以此结尾（斜杠 `\` 是用来解除 `.` 的易容伪装，让它变回普通的点）。
        
2. **目标：** 找一份文件，名字叫“武功”，后面跟着任意数字，但必须是 `.doc` 或 `.docx` 格式。
    
    - **正则连招：** `^武功[0-9]+\.docx?$`
        
    - **拆招解析：** `[0-9]+` 代表数字至少出现一次，`x?` 代表最后那个字母 x 可有可无。
        

> **少侠请留步，牢记一点：** 正则表达式威力极大，通常用在编写代码（Python、JavaScript）或者高级编辑器（如 VS Code）的搜索框里。 **在普通的 Windows 文件夹地址栏里直接输入正则表达式是无效的！**
