### 📁 1. 文件夹（包名 Package）：一律全小写

文件夹在 Java 中被称为“包（Package）”。

- **规则**：只能包含全部**小写**的英文字母和点符（`.`），绝对不能出现大写，尽量不要用下划线，且通常使用名词的单数形式。
    
- **举例**：
    
    - **正确**：`controller`、`service`、`mapper`、`entity`
        
    - **错误**：`Controller`（包含大写）、`user_service`（包含下划线）、`entities`（用了复数）
        

### 📄 2. Java 类名（Class）：大驼峰命名法（UpperCamelCase）

Java 的文件和类名。

- **规则**：每一个单词的首字母都必须**大写**，其余字母小写。
    
- **举例**：
    
    - **正确**：`UserController`、`UserServiceImpl`、`UserMapper`
        
    - **错误**：`userController`（首字母没大写）、`Usercontroller`（第二个单词的首字母没大写）
        

### 🏗️ 三层架构标准命名示范

为了让你更直观地看清楚，假设我们要写一个关于“用户 (User)”的模块，你的标准目录树和文件命名完全应该长这样：

- `entity` （文件夹，实体类包，对应数据库的表）
    
    - `User.java` （类名：只写名词大驼峰）
        
- `mapper` （文件夹，数据访问层，因为你用 MyBatis-Plus，所以习惯叫 mapper）
    
    - `UserMapper.java` （类名：实体类名 + Mapper）
        
- `service` （文件夹，业务逻辑层接口）
    
    - `UserService.java` （类名：实体类名 + Service）
        
    - `impl` （子文件夹，专门放 service 的实现类）
        
        - `UserServiceImpl.java` （类名：接口名 + Impl）
            
- `controller` （文件夹，控制层，负责和前端交互）
    
    - `UserController.java` （类名：实体类名 + Controller）
        

_(额外补充：如果你要在类里面写方法或者变量，比如查询用户的方法，则要使用**小驼峰命名法**，即第一个单词首字母小写，后面的单词首字母大写，例如：`getUserById`。)_

### 🪤 障眼法的真相：操作系统的差异

1. **在本地（Windows系统）**：
    
    Windows 系统的文件系统对大小写是不敏感（不区分大小写）的。在日常使用的命令提示符（cmd）或 PowerShell 环境，乃至整个 Windows 底层逻辑中，`Logo.PNG` 和 `logo.png` 被视为同一个文件。所以，当你的前端代码用全小写去请求时，本地的服务器照样能从硬盘里把那张带有大写字母的图片给你找出来。
    
2. **在生产环境（Linux系统）**：
    
    这是一个巨大的隐患！将来你的项目开发完成，打包部署到真正的线上服务器时，线上环境通常都是 Linux 系统（比如 Ubuntu 等）。**Linux 的文件系统是严格区分大小写**的。在 Linux 眼里，`Logo.PNG` 和 `logo.png` 是两个毫不相干的文件。这时候，你前端写的小写路径去请求，就会直接报 **404 Not Found**，图片当场裂开。
    

这就是程序员常说的经典灵异事件：“明明在我的电脑上跑得好好的，怎么一部署到服务器上图片全没了？”

### 📏 前端静态资源（图片/CSS/JS）的业界命名规范

为了彻底杜绝这种“本地没问题，线上就报错”的情况，前端在处理静态资源文件时，有以下几条铁律规范：

- **一律全小写**：无论是文件名本身，还是文件后缀，全部使用小写字母。
    
    - ✅ **正确**：`background.jpg`
        
    - ❌ **错误**：`Background.JPG`
        
- **单词分隔用中划线或下划线**：坚决不要包含空格，也不推荐使用像 Java 那样的驼峰命名法。一般推荐用中划线 `-`（连字符）。
    
    - ✅ **正确**：`user-avatar-default.png` 或 `user_avatar_default.png`
        
    - ❌ **错误**：`userAvatarDefault.png` 或 `user avatar.png`
        
- **代码引入必须一字不差**：你在 HTML、CSS 或 Vue/React 代码中写路径时，必须和硬盘上的真实文件名在大小写上**保持绝对一致**。
