\# 如何绑定新建Markdwon

\### 2. 桌面右键菜单一键新建（一劳永逸版）



如果希望像新建文本文档一样，直接在桌面右键就能选择新建 Markdown 文件，可以通过一行命令将它加入右键列表：



1\. 用管理员身份运行 \*\*cmd\*\*。

&#x20;   

2\. 复制并运行以下命令：

&#x20;   

&#x20;   DOS

&#x20;   

&#x20;   ```

&#x20;   reg add "HKEY\_CLASSES\_ROOT\\.md\\ShellNew" /v NullFile /f

&#x20;   ```

&#x20;   

3\. 刷新一下桌面，以后在任何地方\*\*右键 -> 新建\*\*，就能直接看到 Markdown 文件的选项了，操作极其顺手。
