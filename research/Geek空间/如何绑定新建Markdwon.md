# 如何绑定新建Markdwon

少侠，在Windows系统下快速新建Markdown（`.md`）文件有几种非常高效的方法，你可以根据当下的操作习惯来选择：

### 1. 终端命令行快速创建（极速版）

如果你习惯敲代码，可以直接呼出常用的 cmd 或 PowerShell 进行创建：

- **在 cmd 中**：
    
    DOS
    
    ```
    type nul > 你的文件名.md
    ```
    
- **在 PowerShell 中**：
    
    PowerShell
    
    ```
    New-Item 你的文件名.md
    ```
    

_(如果你正好切到了你配置好的 WSL2 Ubuntu 环境里，那直接用老规矩敲 `touch 你的文件名.md` 就可以了。)_

### 2. 桌面右键菜单一键新建（一劳永逸版）

如果希望像新建文本文档一样，直接在桌面右键就能选择新建 Markdown 文件，可以通过一行命令将它加入右键列表：

1. 用管理员身份运行 **cmd**。
    
2. 复制并运行以下命令：
    
    DOS
    
    ```
    reg add "HKEY_CLASSES_ROOT\.md\ShellNew" /v NullFile /f
    ```
    
3. 刷新一下桌面，以后在任何地方**右键 -> 新建**，就能直接看到 Markdown 文件的选项了，操作极其顺手。
    

### 3. 文本重命名法（最常规）

1. 在桌面或文件夹空白处 **右键 -> 新建 -> 文本文档**。
    
2. 直接将文件后缀名从 `.txt` 改为 `.md` 即可。
    
    _(注意：如果看不到后缀名，需要在资源管理器顶部的“查看”菜单中，勾选“文件扩展名”。)_
    

干就完了，少侠，挑一个最顺手的用起来吧！
