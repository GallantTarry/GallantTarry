# 如何自己制作一个软件签证证书？

独立开发者打包的 `.exe` 软件常被杀毒软件（如火绒）误报拦截。在无预算购买商业证书的情况下，制作个人自签名证书（Self-Signed Certificate）是绕过静态扫描的极客方案。以下是精简后的证书制作与签名完整教程。

  

## 准备工作：获取 SignTool

安装 Visual Studio 时，勾选安装 **Windows SDK**，系统会附带微软官方签名工具 `signtool.exe`。

  

- 默认路径参考：`C:\Program Files (x86)\Windows Kits\10\bin\10.0.xxxxx.0\x64\signtool.exe`
    
      
    
- 建议选择 `x64` 目录下的版本。复制并保存该绝对路径备用。
    
      
    

## 步骤一：生成自签名证书

通过 PowerShell 调用系统底层加密接口生成证书。

  

1. 按 `Win + X` 打开 **终端 (管理员)** 或 **PowerShell**。
    
      
    
2. 运行以下命令：
    
      
    

PowerShell

```
New-SelfSignedCertificate `
    -Type CodeSigningCert `
    -Subject "CN=土块, E=w1961459892@gmail.com, O=土块的小屋, L=宿迁, S=江苏, C=CN" `
    -FriendlyName "土块的签名证书" `
    -CertStoreLocation "Cert:\CurrentUser\My" `
    -NotAfter (Get-Date).AddYears(20)
```

> **说明**：该命令会在当前用户的系统证书库中，创建一张有效期 20 年、主体信息包含“土块的小屋”的代码签名专用证书。
> 
>   

## 步骤二：导出私钥证书 (.pfx)

为了方便随时调用，需将证书及私钥打包导出。

  

1. 按 `Win + R` 输入 `certmgr.msc` 打开**证书管理器**。
    
      
    
2. 依次展开左侧的 **个人 -> 证书**，找到刚生成的“土块的签名证书”。
    
      
    
3. 右键点击该证书，选择 **所有任务 -> 导出**。
    
      
    
4. 在导出向导中执行以下配置：
    
      
    - 勾选 **“是，导出私钥”**（必须带私钥才能用于签名）。
        
          
        
    - 格式选择 **“个人信息交换 - PKCS #12 (.PFX)”**。
        
          
        
    - 勾选并设置密码（例：`574185`），加密方式选 `AES256-SHA256`。
        
          
        
5. 命名并保存文件（如 `tukuai.pfx`）。
    
      
    

> **提示**：默认路径可能保存在 System32 目录下，建议导出时点击“浏览”直接存至桌面。
> 
>   

## 步骤三：为软件执行签名

使用 `signtool` 将证书印章盖在目标 `.exe` 文件上。打开终端运行以下命令：

  

DOS

```
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe" sign /f "C:\Users\w1961\Desktop\tukuai.pfx" /p "574185" /tr "http://timestamp.digicert.com" /td sha256 /fd sha256 "C:\Users\w1961\Desktop\BlackHolev1.2.3.exe"
```

**核心参数解析：**

  

- `/f` 与 `/p`：指定桌面的证书路径与对应的私钥密码。
    
      
    
- `/tr`：连接 DigiCert 官方服务器打上**时间戳**。证明软件是在证书有效期内签名的，即使 20 年后证书过期，该软件依然会被判定为合法有效。
    
      
    
- `/td` 与 `/fd`：时间戳与文件本身均指定使用安全主流的 `sha256` 哈希摘要算法。
    
      
    
- 末尾路径：指定需要签名的目标可执行文件。
    
      
    

## 避坑与维护指南

- **文件占用报错**：若运行签名命令时提示 `SignTool Error: The file is being used by another process`，说明目标软件正在运行。在任务管理器中关闭该程序进程后重新执行即可。
    
      
    
- **签名覆盖与更新升级**：一个 `.exe` 通常只保留最后一次盖上的有效数字签名。如果软件升级了新版本，直接拿命令行对新文件运行一次签名即可，新签章会自动完美覆盖旧痕迹。
