# 什么是MAC地址如何获取，他有什么作用？

**MAC 地址**（Media Access Control Address，媒体存取控制地址）是网络设备的**物理地址**。如果你把 IP 地址比作网络世界的“收货地址”，那么 MAC 地址就是网络设备的“身份证号”。

  

### 什么是 MAC 地址？

- **硬件绑定：** 它是网络设备制造商在生产网卡时，直接烧录在硬件内部的一个地址。理论上，世界上每一块网卡（包括电脑的以太网卡、Wi-Fi 模块、手机的网络芯片等）出厂时都有一个全球唯一的 MAC 地址。
    
      
    
- **外观格式：** 它通常由 48 位二进制数构成，为了方便人类阅读，一般被转换为 6 组十六进制数字，中间用冒号或连字符隔开。例如：`00:1A:2B:3C:4D:5E` 或 `00-1A-2B-3C-4D-5E`。
    
      
    

### MAC 地址有什么作用？

虽然在互联网上冲浪主要靠 IP 地址，但在底层和局域网中，MAC 地址是不可或缺的：

  

- **局域网内的数据传输：** IP 地址只负责将数据包送到你所在的网络（比如你的路由器）。当数据到达路由器后，路由器和交换机必须依靠 MAC 地址，才能在局域网内精确地将数据交给你的电脑，而不是你家人的手机。
    
      
    
- **网络权限控制（防蹭网）：** 在路由器的后台设置中，你可以使用“MAC 地址过滤”功能。你可以将自己设备的 MAC 地址加入白名单，这样即使别人知道了你的 Wi-Fi 密码，只要他的设备 MAC 地址不在名单内，依然无法连接网络。
    
      
    
- **固定 IP 绑定：** 如果你在做开发、搭建本地服务器或运行自动化脚本，通常需要设备保持固定的局域网 IP。你可以在路由器中将你设备的 MAC 地址与某个 IP 绑定，这样每次开机，DHCP 服务器都会把同一个 IP 分配给你。
    
      
    
- **设备身份识别：** 许多公共 Wi-Fi（如酒店、机场）需要网页认证，它们就是通过记录你设备的 MAC 地址来判断你是否已经登录或是否超时。
    
      
    

> **隐私保护机制：** 正因为 MAC 地址相当于设备的“指纹”，容易被商场或公共场所用来追踪你的行动轨迹。因此，现代智能手机（iOS/Android）和 Windows 电脑在连接 Wi-Fi 时，默认会开启**随机 MAC 地址**功能，即每次连接不同的网络时生成一个虚假的 MAC 地址来保护隐私。
> 
>   

### 如何获取 MAC 地址？

对于经常需要配置环境或调试网络的场景，使用命令行获取是最快捷的方式：

  

**Windows 系统：**

  

1. 按 `Win + R` 键，输入 `cmd` 并回车打开命令提示符。
    
      
    
2. 输入 `ipconfig /all` 并回车。
    
      
    
3. 找到你当前正在使用的网络适配器（如“无线局域网适配器 WLAN”或“以太网适配器”）。
    
      
    
4. 其中的 **物理地址 (Physical Address)** 这一项，就是该网卡的 MAC 地址。
    
    _(注：也可以直接输入 `getmac` 命令，它会简洁地列出所有网卡的 MAC 地址)_
    
      
    

**Linux 系统（如 Ubuntu）：**

打开终端，输入 `ip link` 或 `ifconfig`。在输出的网卡信息中，找到 `link/ether` 后面的 12 位字符，即为 MAC 地址。

  

**macOS 系统：**

打开“系统设置” > “网络”，选择你当前连接的网络，点击“详细信息” > “硬件”，即可看到 MAC 地址。

  

**手机端：**

通常在“设置” > “关于手机” > “状态信息” 或“WLAN/Wi-Fi”的详细设置中，可以找到“WLAN MAC 地址”或“Wi-Fi 地址”。
