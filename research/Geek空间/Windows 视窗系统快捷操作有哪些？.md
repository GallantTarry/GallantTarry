# Windows 视窗系统快捷操作有哪些？

## Windows 系统常用快捷键

| 快捷键 | 功能说明 |
| --- | --- |
| **Win + D** | 快速显示或隐藏桌面 |
| **Win + E** | 打开文件资源管理器 |
| **Win + L** | 锁定电脑屏幕 |
| **Win + V** | 打开剪贴板历史记录（可查看复制过的多条文本和图片） |
| **Win + Shift + S** | 调出系统自带的高级截屏工具（支持矩形、任意形状、窗口截图） |
| **Win + 方向键 (↑↓←→)** | 窗口快速分屏（最大化、最小化或贴靠屏幕左右侧） |
| **Win + I** | 快速打开系统“设置” |
| **Win + . (句号)** | 调出表情符号 (Emoji)、颜文字和特殊符号面板 |
| **Alt + Tab** | 快速切换当前打开的应用程序窗口 |
| **Ctrl + Shift + Esc** | 直接打开任务管理器 |

## 核心操作与虚拟桌面管理

| 快捷键操作 | 核心功能 | 场景与备注 |
| --- | --- | --- |
| **Win + ← / →** | 窗口迅速左右分屏 | 告别手动拖拽，左侧写代码、右侧看文档的最强搭配 |
| **Win + ↑ / ↓** | 窗口最大化 / 还原原始大小 | 瞬间接管窗口尺寸控制权 |
| **Win + 1~9** | 启动 / 切换任务栏对应程序 | 盲操神器，按任务栏从左到右顺序直达（如IDE、浏览器） |
| **Win + Tab** | 呼出任务视图，创建虚拟桌面 | 物理隔离工作（代码/文档）与娱乐（音乐/游戏）空间 |
| **Win + Ctrl + ← / →** | 快速切换虚拟桌面 | 实现沉浸式状态切换。*注：会与电脑版微信语音输入冲突，需改键* |

## 快捷键失效排查指南

| 常见原因 | 表现特征 | 排查与解决方式 |
| --- | --- | --- |
| **游戏防误触锁键** | 按 Win 键无任何反应 | **硬解锁**：按键盘 **`Fn + Win`**<br>

<br>**软解锁**：进入 Lenovo Vantage，关闭“Windows 键锁定” |
| **系统分屏功能关闭** | 能打开开始菜单，但无法分屏 | 按 **`Win + I`** 进设置 -> 系统 -> 多任务处理 -> 开启“贴靠窗口” |
