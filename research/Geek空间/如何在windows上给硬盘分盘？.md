# 如何在windows上给硬盘分盘？

在 Windows 上给硬盘分盘（也就是划分新分区）不需要借助任何第三方软件，直接使用系统内置的工具就能无损搞定。

  

这个过程本质上是从已有分区（比如 C 盘）中“挤”出一块空白空间，然后把它初始化成一个新盘。以下是具体操作流程：

  

**1.打开“磁盘管理”：**

右键点击屏幕底部的 **Windows 开始图标**（或者直接按 `Win + X` 快捷键），在弹出的菜单中选择 **磁盘管理**。

  

**2.压缩现有卷：**计算好需要的空间大小（1GB = 1024MB）。

1. 在磁盘列表中，找到可用空间较多的驱动器（比如 C 盘），**右键**点击它，选择 **压缩卷**。
    
      
    
2. 系统会花几秒钟查询可用空间。在弹出的窗口中，找到 **输入压缩空间量(MB)** 这一栏。
    
      
    
3. 输入你想分给新盘的大小。比如你想分出 100GB，就输入 `102400`。
    
      
    
4. 点击 **压缩**。完成后，你会看到该磁盘条的右侧多出了一块黑色的 **未分配** 空间。
    
      
    

**3.新建简单卷：**将空白空间转化为真正的磁盘。

1. **右键**点击那块黑色的 **未分配** 空间，选择 **新建简单卷**。
    
      
    
2. 弹出向导窗口后，点击 **下一页**。
    
      
    
3. “简单卷大小”默认就是你刚才分出来的最大值，直接点击 **下一页**。
    
      
    

**4.分配盘符与格式化：**

1. **分配驱动器号：** 在下拉菜单里选一个你喜欢的字母（比如 D、E、F），点击 **下一页**。
    
      
    
2. **格式化分区：** 保持默认设置即可（文件系统选 **NTFS**，分配单元大小选 **默认**，勾选 **执行快速格式化**）。你可以修改“卷标”给新盘起个容易辨识的名字（比如“代码盘”、“资料盘”）。
    
      
    
3. 点击 **下一页**，然后点击 **完成**。
    
      
    

当你看到那块黑色的区域变成蓝色，并且电脑弹窗提示发现新驱动器时，分盘就大功告成了，你可以直接去“此电脑”里使用这个新盘。
