# 💯下载软件时，x86、x64、ARM64 该选哪个？

**先看软件要在哪里运行，再选和那个系统架构相符的版本。** 比如，拯救者 R9000P 用的是 AMD 锐龙 9 7945HX。在它的 64 位 Windows 桌面上装软件，选 `win-x64`。如果要把同一个工具装进这台电脑的 Ubuntu 子系统，就要看 Linux 版了。

## 一、先查自己的系统，再看下载页

**Windows** 打开「设置 → 系统 → 关于」，在「设备规格」中找到「系统类型」。**Mac** 点左上角苹果菜单 →「关于本机」，看「芯片」或「处理器」一栏。

| 系统里看到的结果 | 下载页该选哪一项 |
| --- | --- |
| Windows · 64 位操作系统，基于 x64 的处理器 | Windows 的 `x64` 或 `amd64` 版 |
| Windows · 64 位操作系统，基于 ARM 的处理器 | Windows 的 `arm64` 版 |
| Windows · 32 位操作系统，处理器属于 x86 家族 | Windows 的 `x86`（32 位）版，即使处理器本身支持 x64 |
| Mac ·「芯片」显示 Apple 芯片，如 Apple M2 | Mac 的 `Apple Silicon` 或 `arm64` 版，也可选 `Universal` |
| Mac ·「处理器」显示 Intel | Mac 的 `Intel` 或 `x64` 版，也可选 `Universal` |

Mac 下载页上的 `Universal` 是通用版。它在同一个应用里装入两种架构的代码，两类 Mac 都可以直接运行对应的那一份。

**Debian、Ubuntu、Raspberry Pi OS** 可以在终端运行下面的命令，查看当前系统默认安装哪种软件包。用 WSL（Windows 里的 Linux 子系统）时，就在要装软件的那个 Linux 终端里查。

```bash
dpkg --print-architecture
```

| 命令输出 | Linux 下载页上对应的版本 |
| --- | --- |
| `amd64` | 64 位 x86，常标为 `amd64`、`x86_64` 或 `x64` |
| `arm64` | 64 位 ARM，常标为 `arm64` 或 `aarch64` |
| `armhf` | 32 位 ARM，选发布者明确支持该系统和机型的 `armhf` 包 |
| `i386` | 32 位 x86，选项目提供的 32 位 x86 版 |

> 同一台树莓派 4 可以装 32 位或 64 位 Raspberry Pi OS。哪怕芯片支持 64 位，只要命令显示 `armhf`，就按 32 位系统选包。下载页没有列出你的型号时，优先从当前系统的软件源安装。

## 二、看懂文件名里的两条线索

以 `tool-windows-amd64.zip` 为例，`windows` 告诉你它在哪个系统里运行，`amd64` 告诉你它为哪种处理器架构编译。`.zip` 只说明文件经过压缩。各项目命名略有不同，下载前也要确认自己的系统版本符合软件要求。

**为什么 Intel 电脑也能选 `amd64`？** AMD 最早推出了这套 64 位 x86 扩展，后来 Intel 处理器也支持它，所以这个名字沿用至今。讲 CPU 时，x86 可以指整个家族。Windows 下载页把 **`x86` 和 `x64` 并排列出**时，前者通常是 32 位版，后者是 64 位版。

> 架构说明芯片能读懂哪些指令。想知道电脑跑得快不快、耗不耗电，还得看具体芯片和运行的软件。选安装包时，看系统和架构就比凭电脑品牌猜更准。

## 四、只有其他架构的版本怎么办？

- **Apple 芯片 Mac 只有 Intel 版可下。** 先查这款应用和当前 macOS 是否支持 Rosetta。它能把受支持的 Intel 应用翻译给 Apple 芯片运行。如果下载页提供 Apple 芯片版或通用版，直接选其中之一。
- **ARM 电脑上的 Windows 11 只有 x64 或 x86 版可下。** 许多普通应用可以通过系统模拟运行。打印机等设备的驱动程序则要选支持 ARM64 的版本。
