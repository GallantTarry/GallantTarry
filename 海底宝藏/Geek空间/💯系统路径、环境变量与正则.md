# 💯系统路径、环境变量与正则

## 一、 路径 (Paths) —— 寻人的基础地图

这俩概念其实非常简单，咱们用最直白的说法一句话搞定：

- **绝对路径** = **完整的收货地址**（比如：某省某市某区某街道某号）。不管你现在身在何处，只要照着这个地址找，就一定能定位到同一个目标。
- **相对路径** = **问路的指南**（比如：从这往前走两个路口，右拐）。它完全取决于你**现在站在哪里**。

### 1. 绝对路径 (Absolute Path)

它是一条“走到底”的完整路线，直接从最顶层的起点开始写起：

- **在 Windows 系统中**：本机文件通常以**盘符加反斜杠**（如 `C:\`、`D:\`）开头；如果是局域网共享或 NAS 上的文件，则是没有盘符的完整网络路径（UNC 路径），以双反斜杠 `\\` 开头。
  - 本机示例：`C:\Users\Shaoxia\Desktop\秘籍.txt`
  - 网络示例：`\\Server\Share\秘籍.txt`
- **在 macOS / Linux 系统中**：总是以正斜杠 `/`（根目录）开头。
  - 示例：`/home/shaoxia/documents/秘籍.txt`

**优点**：非常精准，无论你当前在电脑的哪个文件夹里操作，绝对路径指向的位置都不会变。  
**缺点**：写起来长，而且跨电脑容易水土不服——把项目发给别人，对方电脑上很可能没有 `C:\Users\Shaoxia\` 这个目录，代码就会报错。

### 2. 相对路径 (Relative Path)

它是一条“从脚下出发”的路线，**基于你当前所在的文件夹（工作目录）**来寻找目标。这里有两个必须记住的“暗号”：

- `.`（单点）：代表**当前**所在的文件夹。
- `..`（双点）：代表**上一级**文件夹（也就是往外退一层）。

**举个实战例子：**

假设你现在正站在 `C:\Users\Shaoxia\Desktop`（桌面）这个文件夹里：

1. 你要找同在桌面上的 `秘籍.txt`。
   - 相对路径直接写：`秘籍.txt`（或者 `.\秘籍.txt`，在代码和跨平台工具里也常写成 `./秘籍.txt`）
2. 你要找位于上一级文件夹（`Shaoxia`）里的 `照片.png`。
   - 相对路径就是：`..\照片.png`（意思是：退到上一级，找到照片）
3. 你要找上一级文件夹里，`Downloads` 文件夹中的 `武器.exe`。
   - 相对路径就是：`..\Downloads\武器.exe`

**优点**：简短灵活，非常适合写代码和做项目。只要项目内部目录结构不变，并且运行时的**出发点（当前工作目录）**一致，整个项目文件夹打包发给别人也能正常运行。  
**避坑提醒**：东西还放在原处，但如果你换了出发点（比如终端没有先 `cd` 进项目目录，而是站在外层目录去运行程序），照着同一句“往上一层走 (`..`)”就会走到别处，导致找不到文件。

**快速对比总结**

| 特性 | 绝对路径 (Absolute) | 相对路径 (Relative) |
| :--- | :--- | :--- |
| **起点** | 盘符根目录（如 `C:\`）、`/` 或网络路径 `\\` | 当前所在的文件夹（工作目录） |
| **长度** | 通常较长 | 通常较短 |
| **可移植性** | 差（换台电脑目录名可能不同） | 好（目录结构与出发点不变时，整体搬移不受影响） |
| **适用场景** | 指向系统固定位置、配置文件中的全局路径 | 代码编写、网页开发、项目内部文件互相引用 |

## 二、 环境变量与特殊符号 (`%`) —— 江湖代号与百变通配

如果把“路径”当成寻人的地图，那么环境变量就是“动态传送门”，而通配符与正则表达式则是按线索抓人的“搜捕令”。

在计算机世界里，`%` 常在两个截然不同的场景下出场，而且**极其讲究输入的位置**，千万别串台：

### 场景 A：Windows 里的“任意门”（环境变量）

因为每台电脑的用户名不一样（你的电脑是 `C:\Users\Shaoxia`，朋友的是 `C:\Users\Daxia`），如果把绝对路径写死，换台电脑就失灵了。为此，操作系统提供了一批“动态代号”——**环境变量 (Environment Variables)**。

不过，在不同窗口里调用同一个环境变量，写法并不一样（以临时目录 `TEMP` 为例）：

- **在 `Win + R`“运行”窗口 或 文件资源管理器地址栏**：成对加百分号，输入 `%TEMP%` 并回车，直接打开对应文件夹。
- **在 CMD（命令提示符）**：同样用百分号，输入 `echo %TEMP%` 查看它指向的路径。
- **在 PowerShell**：改用美元符前缀，输入 `$env:TEMP` 回车查看路径（在 PowerShell 里直接敲 `%TEMP%` 不会被展开）。

最常打交道的三个 Windows 环境变量如下：

#### 1. `%USERPROFILE%`：你的“个人大本营”

- **它的真身**：当前登录用户的个人主目录。
- **默认路径**：通常是 `C:\Users\你的用户名`。
- **里面有什么**：默认存放着你的“桌面 (`Desktop`)”、“下载 (`Downloads`)”、“文档 (`Documents`)”、“图片”等个人文件夹。
- **怎么用与避坑**：`%USERPROFILE%` 会精准找到当前用户的主目录——在你电脑上指向 `Shaoxia`，在朋友电脑上指向 `Daxia`。**当桌面还在默认位置时**，后面接上 `\Desktop`（即 `%USERPROFILE%\Desktop`）就能找到桌面；但如果用户开启了 OneDrive 桌面备份，或手动把桌面迁移到了 D 盘，真实桌面就会搬家（例如变成 `%USERPROFILE%\OneDrive\Desktop`），所以严谨的程序会调用系统接口查询真实桌面路径，而不会死拼 `\Desktop`。

#### 2. `%APPDATA%`：软件的“随身账本”

- **它的真身**：漫游应用程序数据文件夹 (`AppData\Roaming`)，默认隐藏，平时直接逛 C 盘看不见它。
- **默认路径**：通常是 `C:\Users\你的用户名\AppData\Roaming`。
- **里面有什么**：软件的**个人偏好设置、插件配置、账号状态，以及不少单机游戏的存档**（例如 VS Code 的用户配置就住在这里）。
- **应用场景**：当你卸载并重装某款软件时，只要这里的配置没被清除，重新打开软件往往会发现：习惯的快捷键和个性化设置都还在。

#### 3. `%TEMP%`：系统的“临时客栈”

- **它的真身**：当前用户的临时文件夹 (`Temporary folder`)。
- **默认路径**：通常是 `C:\Users\你的用户名\AppData\Local\Temp`。
- **里面有什么**：软件运行、解压大压缩包或安装更新时，临时落脚的缓存与中间文件。
- **动手体验与安全提示**：现在就可以按下 `Win + R`，输入 `%TEMP%` 回车，亲眼看看它跳到了哪个目录，教学目的就达到了。注意：**“临时存放”不等于“现在都能直接删”**——正在运行的软件或等待重启完成的安装程序可能还在读写里面的文件。如果想给 C 盘腾空间，推荐去 **Windows 设置 → 系统 → 存储 → 临时文件** 里按类别勾选清理，比手动全选硬删安全得多。

### 场景 B：数据库与命令行里的“百变星君”（通配符）

假设藏经阁书堆里有一本名字记不全的秘籍，只记得书名里带有**“九阳”**二字，想把《**九阳**神功》、《真**九阳**传》、《新编**九阳**真经白话版》一网打尽——这时候就要派“通配符”出场，代表“零个、一个或多个任意字符”。

但要注意：**不同地盘用的通配符不一样，不能混敲**：

- **在 SQL 数据库查询里**，通配符是百分号 `%`，配合 `LIKE` 写在查询条件中：
  ```sql
  SELECT * FROM 藏经阁 WHERE 书名 LIKE '%九阳%';
  ```
- **在 PowerShell、CMD 或 Windows 文件搜索框里**，通配符是星号 `*`（敲 `%九阳%` 是搜不到文件的！）。例如在 PowerShell 中搜索当前目录下的文件：
  ```powershell
  Get-ChildItem -Filter '*九阳*'
  ```

一句话记牢：**环境变量在 `Win + R` 用 `%TEMP%`、在 PowerShell 用 `$env:TEMP`；模糊匹配在 SQL 用 `'%九阳%'`、在命令行搜文件用 `'*九阳*'`。**

## 三、 正则表达式 (Regex) —— 终极寻人启事

如果说路径是“按地址找人”，通配符是“按关键词捞人”，那正则表达式 (Regular Expression) 就是“按骨相特征抓人”。它有一套精细的规则符号，最常用的基础招式如下：

| 暗号符 | 招式名称 | 作用说明 | 实战举例 |
| :--- | :--- | :--- | :--- |
| `.` | **单体易容** | 匹配**任意单个字符**（换行符除外）。 | `秘籍.卷` 可匹配 `秘籍1卷`、`秘籍A卷`，但不能匹配 `秘籍12卷`（两个字符）或 `秘籍卷`（零个字符）。 |
| `\` | **卸妆还原** | 转义符（反斜杠），解除特殊符号的魔力，还原成**普通字符本身**。 | `\.` 只匹配真正的小数点 `.`，不再充当“任意字符”。 |
| `*` | **影分身术** | 匹配**紧挨着它的前一个字符** 0 次或多次。 | `哇哈*` 可匹配 `哇`（0 次 `哈`）、`哇哈`、`哇哈哈`、`哇哈哈哈`。 |
| `.*` | **万物皆空** | `.` 和 `*` 联手，代表**任意长度（含 0 个）的任意字符**。 | `九阳.*真经` 可匹配 `九阳真经`、`九阳神功真经`。 |
| `[ ]` | **门派令牌** | 匹配方括号内的**任意单个**字符，支持划定范围。 | `[0-9]` 匹配单个数字；`[a-zA-Z]` 匹配单个英文字母。 |
| `^` | **行首定位** | 锁定文本必须从这里**开头**。 | `^User` 只匹配以 `User` 开头的文本。 |
| `$` | **神龙摆尾** | 锁定文本必须在这里**结尾**。 | `\.pdf$` 只匹配以 `.pdf` 结尾的文件名。 |

### 🪤 当堂小测：最容易翻车的第一题

现在桌面上并排摆着三个文件名：

> `秘籍1.txt` 　｜　 `秘籍A.txt` 　｜　 `秘籍12.txt`

如果你想挑出前两个（单字符编号的 `1` 和 `A`），排除第三个（两位数的 `12`），直觉随手写下正则 **`秘籍.txt`**——先猜猜看，这三个文件里哪几个能匹配上？

**实测答案是：全军覆没，一个都匹配不上！**

为什么？数一数字符就明白了：在 `秘籍1.txt` 里，“秘籍”和“txt”之间夹着 **`1` 和 `.` 整整两个字符**，而 `秘籍.txt` 里只有一个 `.`，只能顶替**一个**字符（它反而会去匹配 `秘籍1txt` 或 `秘籍_txt`）。

**正确写法应该是：`^秘籍.\.txt$`**

拆开看，每个符号各司其职：
- 第一个 **`.`**（单体易容）：专门管编号那 **1 个字符**，放行 `1` 或 `A`，同时把占了两个字符的 `12` 拒之门外；
- 后面的 **`\.`**（卸妆还原）：用反斜杠把点还原成扩展名前**真正的小数点**；
- 首尾的 **`^`** 和 **`$`**（首尾锁定）：要求整串文件名严丝合缝，防止误伤 `备份_秘籍1.txt.bak` 这类前后还拖着尾巴的文件名。

### ⚔️ 实战演练：组合连招

掌握了上面的拆招逻辑，再来挑战两道真实筛选题：

1. **目标**：找出所有 2026 年拍摄的 `.jpg` 照片（命名格式如 `2026-05-20.jpg`，即 `2026-两位月份-两位日期.jpg`）。
   - **正则连招**：`^2026-[0-9]{2}-[0-9]{2}\.jpg$`
   - **拆招解析**：`^2026-` 锁死年份开头；`[0-9]{2}` 中的 `{2}` 代表前面的数字必须**恰好连续出现 2 次**（月份和日期各两位）；`\.jpg$` 用反斜杠 `\` 还原小数点，并锁死以 `.jpg` 结尾。

2. **目标**：找出一批名字叫“武功”、后面跟着一串数字，且扩展名必须是 `.doc` 或 `.docx` 的文档（如 `武功1.doc`、`武功99.docx`）。
   - **正则连招**：`^武功[0-9]+\.docx?$`
   - **拆招解析**：`[0-9]+` 中的 `+` 代表前面的数字**至少出现 1 次**（1 位或多位数字都行）；`x?` 中的 `?` 代表前面的字母 `x` **出现 0 次或 1 次**（即可有可无），一招同时兼容 `.doc` 和 `.docx`。

> **💡 使用位置提醒**：正则表达式通常用在代码（如 Python、JavaScript）或专业编辑器（如 VS Code 搜索框，记得点亮搜索框右侧的 **`.*`** 正则开关）里。**在普通的 Windows 文件夹地址栏或资源管理器搜索框里，直接输入正则表达式是无效的！**
