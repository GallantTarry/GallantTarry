# 💯Ubuntu下Vim使用完全指南

> 在 Ubuntu（或 WSL2 Ubuntu）终端里改配置文件、写 C 代码、修 `Makefile` 时，**Vim 是最可靠、随处可用、启动零延迟的编辑器**。本文按真实操作场景整理，重点讲透 **`set paste` 等高频 `:` 指令、日常核心按键、写 C 语言专用配置，以及终端常见翻车急救**。

---

## 一、先确认你用的是完整版 Vim

部分新装 Ubuntu 默认只带了极简版的 `vi`（`vim.tiny`），会出现方向键变成 `ABCD`、退格键不好使、没有语法高亮等问题。建议先确保安装完整版 Vim：

```bash
sudo apt update && sudo apt install -y vim
```

验证版本（能打印出 `VIM - Vi IMproved ...` 即正常）：

```bash
vim --version | head -n 3
```

## 二、30 秒建立核心心法：4 种模式

新手用 Vim 觉得别扭，90% 是因为**没分清当前处在哪个模式**。记住：**拿不准自己在哪个模式时，连按两下 `Esc` 回到普通模式**。

| 模式 | 怎么进入 | 怎么退出 | 主要干什么 |
| :--- | :--- | :--- | :--- |
| **普通模式（Normal）** | 打开文件默认就是；任何模式下按 `Esc` | — | 移动光标、复制、删除、撤销、跳转（**按键盘是执行命令，不是打字**） |
| **插入模式（Insert）** | 在普通模式下按 `i` / `a` / `o` | 按 `Esc` | 正常打字写代码（左下角会显示 `-- INSERT --`） |
| **命令行模式（Command）** | 在普通模式下按英文冒号 `:` 或 `/` | 按 `Esc` 或回车 | 保存退出、开关设置（如 `:set paste`）、搜索替换 |
| **可视模式（Visual）** | 在普通模式下按 `v` / `V` / `Ctrl+v` | 按 `Esc` | 用方向键高亮选中一块文字，批量复制、删除或批量加注释 |

### 1 分钟跑通第一次编辑与保存
在看后面的命令表前，先在终端亲手走通这 4 步，立刻建立手感：
1. 在终端输入 `vim hello.txt` 回车打开/新建文件（默认处于**普通模式**）。
2. 按 **`i`** 进入**插入模式**（左下角出现 `-- INSERT --`），随便敲一句话。
3. 按 **`Esc`** 退回**普通模式**（`-- INSERT --` 消失）。
4. 输入 **`:wq`** 并回车（**命令行模式**：保存并退出），回终端运行 `cat hello.txt` 就能看见刚写的内容。

## 三、重点专项：粘贴外部代码与 `:set paste`（防缩进阶梯错乱）

### 1. 为什么直接粘贴代码有时会乱成一团？
在老旧 SSH 客户端或未启用粘贴保护的终端里，如果你开启了自动缩进（`autoindent` / `smartindent`），从 Windows 复制一段带缩进的 C 代码切到终端粘贴时：
- 终端会把剪贴板里的字符**模拟成你用极快的手速一个字一个字敲进去**；
- 每遇到一个回车，Vim 以为你要换行写新代码，就会**在原本的空格上再叠加一层缩进**；
- 最终一段 20 行的代码每一行都比上一行更靠右，如果第一行是 `//` 注释，后面所有行还可能全部变成 `//` 注释！

### 2. 推荐实操顺序：先直接粘，歪了再用 `:set paste` 兜底

- **日常首选（现代终端直接粘）**：
  Ubuntu 22.04 / 24.04 自带的 Vim 8.2/9.x 配合 Windows Terminal，默认支持**括号粘贴（Bracketed Paste）**，会自动识别整段粘贴。
  > **防坑小技巧**：粘贴大段代码前，建议先按一下 `Esc` 再按 `i` 重新进入插入模式（相当于给撤销打个存档点），然后按 `Ctrl+Shift+V` 直接粘贴。绝大多数情况下格式完好无损。

- **万一粘成了“阶梯状”（3 步保底重贴）**：
  如果发现每一行都比上一行更往右飞，先按 **`Esc`** 回到普通模式，再按 **`u`** 一键撤掉刚粘歪的内容（若不小心撤多了可按 `Ctrl+r` 恢复），然后按这三步重贴：

```text
第 1 步：Esc 回到普通模式，输入  :set paste   并回车
第 2 步：按  i  进入插入模式（左下角出现 -- INSERT (paste) --）
        此时按 Ctrl+Shift+V（或鼠标右键）粘贴
第 3 步：粘贴完按 Esc，再输入  :set nopaste  回车恢复自动缩进
```

> **为什么粘贴完一定要 `:set nopaste`？**
> 因为在 `paste` 模式下，Vim 会临时关闭自动缩进、括号补全和自定义快捷键。如果不关掉，接下来你自己手敲代码时回车不会自动缩进。

### 3. 更省事的进阶方案

- **方案 A：绑一个一键开关热键（常连老旧 SSH 服务器推荐）**
  在 `~/.vimrc` 中加入一行 `set pastetoggle=<F2>`。以后要粘贴前：**`i` → 按一下 `F2` → 粘贴 → 再按一下 `F2`**，不用每次手敲 `:set paste`。
- **方案 B：超长代码直接走外部文件流（WSL2 极速法）**
  如果代码很长，不想走终端粘贴流，在 Ubuntu 终端里可以直接运行 `cat > main.c` 回车，粘贴完按 `Ctrl+D` 结束，或者在 Windows 资源管理器直接编辑。

## 四、高频 `:set` 指令速查表

在 Vim 普通模式下输入 `:` 就能临时生效；**去掉前面的 `:` 写进 `~/.vimrc` 文件里，就会永久生效**。

### 1. 粘贴、换行与编码类
| 指令 | 简写 / 配合 | 作用说明 |
| :--- | :--- | :--- |
| `:set paste` | `:set nopaste` | 开启/关闭粘贴模式，防止外部粘贴代码缩进错乱 |
| `:set ff=unix` | `:set ff=dos` | 把 Windows 复制过来的 `\r\n`（`^M`）转成 Linux 纯 `\n` 换行，再 `:w` 保存即可修复编译报错 |
| `:set fileencodings=utf-8,gbk` | `:e ++enc=gbk`（临时重读） | 自动识别 UTF-8 与从中文 Windows 拷过来的 GBK 源码，避免中文注释乱码 |

### 2. 行号与界面类
| 指令 | 简写 / 关闭 | 作用说明 |
| :--- | :--- | :--- |
| `:set number` | `:set nu` / `:set nonu` | 显示/隐藏左侧行号 |
| `:set relativenumber` | `:set rnu` / `:set nornu` | 显示相对行号（配合 `5j`、`10dd` 跳转/删除多行极爽） |
| `:syntax on` | `:syntax off` | 开启/关闭代码语法高亮 |
| `:set cursorline` | `:set nocursorline` | 高亮当前光标所在整行，找光标不迷路 |
| `:set mouse=a` | `:set mouse=` | 开启/关闭鼠标点击定位和滚轮（**注意**：开启 `mouse=a` 后在终端里用鼠标右键粘贴或划词复制，需要按住 **`Shift`** 键） |

### 3. 缩进与 Tab 类（写 C 与 `Makefile` 必看）
| 指令 | 关闭 / 反义 | 作用说明 |
| :--- | :--- | :--- |
| `:set tabstop=4` | — | 1 个 Tab 字符在屏幕上显示为 4 个空格宽度 |
| `:set shiftwidth=4` | — | 自动缩进或 `>>` / `<<` 缩进一级的宽度为 4 |
| `:set expandtab` | `:set noexpandtab` | 按 `Tab` 键时自动转成空格（写 C/Python 推荐开启） |
| `:set noexpandtab` | — | **写 `Makefile` 必开！** 强制保留真 `Tab`（`0x09`），否则 `make` 会报错 `missing separator` |
| `:set autoindent` | `:set noautoindent` | 新起一行时继承上一行的缩进 |
| `:set smartindent` | `:set nosmartindent` | C 语言风格智能缩进（遇到 `{` 回车自动多缩一级） |

### 4. 搜索体验类
| 指令 | 关闭 / 配合 | 作用说明 |
| :--- | :--- | :--- |
| `:set hlsearch` | `:noh`（临时取消高亮） | 搜索匹配到的所有词高亮显示 |
| `:set incsearch` | `:set noincsearch` | 边打搜索词边实时跳转预览 |
| `:set ignorecase` | `:set smartcase` | 搜索忽略大小写；加上 `smartcase` 后只要输入包含大写字母就自动精确匹配 |

## 五、日常高频操作全清单（按场景查阅）

### 1. 打开、保存与退出
| 命令 | 作用 | 备注 |
| :--- | :--- | :--- |
| `vim main.c` | 打开或新建文件 | — |
| `vim +25 main.c` | 打开文件并直接跳到第 25 行 | 编译器报错提示第 25 行时超好用 |
| `:w` | 保存（Write） | 不退出 |
| `:q` | 退出（Quit） | 没改动时才能退 |
| `:wq` 或 `:x` | 保存并退出 | `:x` 仅在文件有修改时才写入更新时间 |
| `:q!` | **不保存强制退出** | 改乱了想重来时救命用 |
| `:w !sudo tee %` | **忘记用 `sudo` 打开系统文件时强行保存** | 回车输入密码后按 `L` 重载（改 `/etc/` 配置神技） |

### 2. 光标高速移动（普通模式）
| 按键 | 作用 | 记忆技巧 |
| :--- | :--- | :--- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 | 方向键也能用，熟练后不用手离开主键盘区 |
| `0` / `^` / `$` | 行首（第1列） / 第一个非空字符 / 行尾 | `$` 在正则里也是行尾 |
| `w` / `b` | 跳到下个单词开头 / 上个单词开头 | **w**ord / **b**ack |
| `gg` / `G` | 文件第 1 行 / 文件最后一行 | — |
| `25G` 或 `:25` | 精准跳转到第 25 行 | — |
| `Ctrl+u` / `Ctrl+d` | 向上 / 向下翻半屏 | **u**p / **d**own |
| **`%`** | **在匹配的 `(` `)`、`{` `}` 之间来回跳转** | 查 C 语言少没少花括号的神键 |

### 3. 插入、删除、复制、撤销（普通模式）
| 按键 | 作用 | 备注 |
| :--- | :--- | :--- |
| `i` / `a` | 在光标前 / 光标后插入 | **i**nsert / **a**ppend |
| `I` / `A` | 跳到本行最前 / 本行末尾并进入插入 | 补行尾分号 `;` 直接按 `A;` |
| `o` / `O` | 在当前行下方 / 上方新开一行并插入 | **o**pen new line |
| `x` | 删除光标所在的单个字符 | 等同 `Delete` |
| `dd` / `5dd` | 剪切（删除）当前行 / 向下 5 行 | Vim 里“删除”本质是“剪切”，按 `p` 能贴出来 |
| `dw` / `d$` | 删除一个词 / 删到行尾 | — |
| `ci"` / `di(` | 清空引号 `""` 内内容并进入编辑 / 删除 `()` 内内容 | 改函数参数或字符串神技（**c**hange **i**nside `"`） |
| `yy` / `5yy` | 复制当前行 / 向下 5 行 | **y**ank |
| `p` / `P` | 整行（`yy`/`dd`）：贴到当前行下方 / 上方；字符或词（`x`/`dw`）：贴到光标后 / 前 | **p**ut（表现取决于复制/删除的是整行还是字符） |
| `u` / `Ctrl+r` | **撤销（Undo）** / **重做（Redo）** | 按错救命键 |
| `>>` / `<<` | 当前行向右 / 向左缩进一级 | — |
| **`gg=G`** | **全文一键自动格式化缩进** | 代码缩进乱掉时连续按 `g g = G` 瞬间对齐 |

### 4. 搜索与批量替换（命令行模式）
| 指令 | 作用 |
| :--- | :--- |
| `/printf` | 向下搜索 `printf`（按 `n` 找下一个，`N` 找上一个） |
| `?main` | 向上搜索 `main` |
| `*` | 在普通模式下，直接搜索光标当前踩着的整个单词 |
| `:noh` | 清除搜索后的黄色高亮背景 |
| `:%s/old/new/g` | 全文把 `old` 替换成 `new`（`%` = 全文，`g` = 每行所有匹配） |
| `:%s/old/new/gc` | 全文替换，但**每次替换前询问确认**（`y` 替换 / `n` 跳过 / `a` 全部） |
| `:10,20s/old/new/g` | 仅在第 10 到 20 行之间替换 |

### 5. 可视模式：C 代码批量注释 / 取消注释（必学绝招）
想一口气给第 10～15 行 C 代码加上 `// ` 注释：
1. 光标移到第 10 行行首，按 **`Ctrl + v`** 进入**列块可视模式**（`VISUAL BLOCK`）。
2. 按 `j`（或向下方向键）选到第 15 行行首。
3. 按大写 **`I`**（Shift + i），输入 **`// `**（斜杠加空格）。
4. 按一下 **`Esc`**，等半秒——所有选中行瞬间同时加上 `// `！

**批量取消注释**：`Ctrl + v` 选中前面几列 `// ` → 按 `d` 或 `x` 一键删除。

## 六、Ubuntu + C 语言专属实战技巧

### 1. 不退出 Vim，一键保存、编译并运行当前 `.c` 文件
Vim 默认在执行 `:!` 外部命令前**不会自动保存缓冲区**（若漏了保存，`gcc` 读取的仍是磁盘上的旧代码）。在普通模式下用 `|` 把保存 `:w` 串在前面即可一键搞定（`%` 代表当前文件名，`%<` 代表去掉后缀的文件名）：

```vim
:w | !gcc -Wall -Wextra -std=c11 -g % -o %< && ./%<
```

运行完按回车即可回到代码界面；也可以在 Windows Terminal 里用 `Alt + Shift + D` 分出左右两个 Ubuntu 窗格：**左边 Vim 改代码，右边终端跑 `gcc` / `make` / `gdb`**，效率最高。

### 2. 一键生成 C 语言专用 `~/.vimrc` 配置文件
> **注意**：首次配置可直接整段复制执行（第一行会自动把已有的 `~/.vimrc` 备份为 `~/.vimrc.bak`）。如果你原本已有自定义 `.vimrc`、只想挑其中几项（如 `F2` 粘贴开关），请用 `vim ~/.vimrc` 打开原文件按需追加，不要直接整段覆盖。

在 Ubuntu 终端执行下面整段命令，即可生成一份干净、无插件依赖、兼顾 C 语言与 `Makefile` 的黄金配置：

```bash
[ -f ~/.vimrc ] && cp ~/.vimrc ~/.vimrc.bak && echo "已将原配置备份至 ~/.vimrc.bak"
cat << 'EOF' > ~/.vimrc
" === 基础编码与中文防乱码（兼容 Windows GBK 源码） ===
set nocompatible
set encoding=utf-8
set fileencodings=ucs-bom,utf-8,gbk,cp936,latin1
syntax on

" === 界面显示 ===
set number                  " 显示行号
set cursorline              " 高亮当前行
set showcmd                 " 右下角显示正在输入的命令
set ruler                   " 显示光标行列坐标
set scrolloff=5             " 上下滚动预留 5 行视野

" === C 语言友好缩进 ===
set tabstop=4
set shiftwidth=4
set softtabstop=4
set expandtab               " Tab 转 4 空格
set autoindent
set smartindent

" === 关键防坑：Makefile 必须用真实 Tab ===
autocmd FileType make setlocal noexpandtab tabstop=4 shiftwidth=4

" === 粘贴防乱码：按 F2 一键切换 paste / nopaste ===
set pastetoggle=<F2>

" === 搜索体验 ===
set hlsearch
set incsearch
set ignorecase
set smartcase

" === 括号匹配与退格键修复 ===
set showmatch
set backspace=indent,eol,start

" === 允许鼠标定位（在终端中划词或右键粘贴请按住 Shift） ===
set mouse=a
EOF
```

## 七、Ubuntu 终端使用 Vim 的 5 个常见坑

1. **按了 `Ctrl + S` 习惯性想保存，结果屏幕彻底卡死**
   - **原因**：`Ctrl + S` 在 Linux 终端里是“暂停屏幕输出（XOFF）”，不是保存！
   - **急救**：按 **`Ctrl + Q`** 立刻恢复正常。
2. **输入法是中文时，按 `Esc` 半天退不回普通模式，按键还打出拼音**
   - **原因**：中文输入法吃掉了按键。
   - **习惯**：切到英文输入法再操作 Vim；或者用 **`Ctrl + [`** 替代 `Esc` 键（手不用离开字母区，效果完全等同 `Esc`）。
3. **打开文件突然提示 `Found a swap file by the name ".main.c.swp"`**
   - **原因**：上次写到一半终端直接关掉了（或另一个窗口正开着这个文件）。
   - **处理**：确认没有其他窗口正在编辑后，如果上次有未保存内容先选 `(R)ecover` 恢复再保存，最后删除隐藏的 `.swp` 缓存文件（如 `rm .main.c.swp`），或者在提示界面按 `(D)elete it`。
4. **开启 `set mouse=a` 后，鼠标左键拖不出终端复制、右键弹不出粘贴**
   - **原因**：鼠标事件被 Vim 接管了（用来点光标定位）。
   - **处理**：在 Windows Terminal 里**按住 `Shift` 键再拖动或右键**，就能强制使用终端原生复制/粘贴；或直接按 **`Ctrl + Shift + V`** 粘贴（若遇到缩进错乱可按 `F2` 或用 `:set paste` 重贴）。
5. **从 Windows 粘过去的文件编译报 `stray '\'` 或结尾多出 `^M`**
   - **处理**：在 Vim 里输入 `:set ff=unix` 回车，再 `:wq` 保存即可彻底转为 Linux 换行符。
