# 💯Ubuntu极简入门指南

Linux 命令看起来像密码，其实 **90% 都是英语单词的缩写**。看懂缩写原意，根本不用死记硬背。

所有命令都遵循同一个公式：

```text
命令  -选项  目标
```

例如 `rm -r test`：`rm` 是动作（删除），`-r` 是选项（递归），`test` 是目标（要删的文件夹）。

---

## 一、先认懂 9 个核心符号（看懂它们，命令就懂了一半）

| 符号   | 英文原意 / 读法               | 白话解释                          | 常见例子                      |
| ---- | ----------------------- | ----------------------------- | ------------------------- |
| `/`  | **Root**（根） / 路径分隔符     | 放在最开头表示整个系统的“总根目录”；放在中间用来隔开层级 | `/home/test`              |
| `~`  | **Home**（家目录，符号叫 Tilde） | 代表“你自己专属的个人文件夹”               | `cd ~`（一键回家）              |
| `.`  | **Current**（当前目录）       | 代表“我现在正站着的这个文件夹”              | `./hello`（运行当前目录下的 hello） |
| `..` | **Parent**（父目录）         | 代表“上一级文件夹”                    | `cd ..`（退回上一层）            |
| `-`  | **Option / Flag**（选项前缀） | 告诉系统后面跟的是“开关参数”，不是文件名         | `ls -a`（打开显示隐藏文件的开关）      |
| `>`  | **Redirect**（重定向·覆盖）    | 把屏幕输出改道写进文件（会**清空原内容**）       | `ls > list.txt`           |
| `>>` | **Append**（重定向·追加）      | 把屏幕输出接着写到文件**末尾**（不清空原内容）     | `echo hi >> log.txt`      |
| `\|` | **Pipe**（管道）            | 把左边命令的结果，直接喂给右边命令继续处理         | `ls \| grep c`            |
| `&&` | **AND**（并且）             | 前一条命令**没报错**，才继续执行后一条         | `gcc a.c -o a && ./a`     |

## 二、认路和逛目录（3 个必会命令）

| 命令 / 参数 | 英文原意 | 作用 | 常用示例 |
| --- | --- | --- | --- |
| `pwd` | **P**rint **W**orking **D**irectory | 打印“我现在在哪个文件夹” | `pwd` |
| `ls` | **L**i**s**t | 列出当前目录里有什么文件 | `ls` |
| `ls -a` | `-a` = **a**ll（全部） | 连隐藏文件（`.` 开头的文件）一起列出来 | `ls -a` |
| `ls -l` | `-l` = **l**ong（长格式） | 显示详细信息（权限、大小、修改时间） | `ls -l` |
| `ls -la` | `-l` + `-a` 合并简写 | 显示**全部**文件的**详细**信息（最常用） | `ls -la` |
| `cd` | **C**hange **D**irectory | 切换文件夹 | `cd c`（进入 c 文件夹） |
| `cd ..` | `..` = 上一级 | 退回上一级目录 | `cd ..` |
| `cd ~` | `~` = 家目录 | 一键回到个人家目录 | `cd ~` |
| `cd -` | `-` = 上一次位置 | 在刚才待过的两个目录之间来回切 | `cd -` |

## 三、新建、复制、改名、删除（6 个高频文件操作）

| 命令 / 参数 | 英文原意 | 作用 | 常用示例 |
| --- | --- | --- | --- |
| `mkdir` | **M**a**k**e **Dir**ectory | 新建文件夹 | `mkdir test` |
| `mkdir -p` | `-p` = **p**arents（父目录） | 一次建多层嵌套文件夹（上级不存在就自动补） | `mkdir -p a/b/c` |
| `touch` | **Touch**（轻触一下） | 文件不存在就新建一个空文件；存在就刷新时间 | `touch hello.c` |
| `cp` | **C**o**p**y | 复制单个文件 | `cp a.c b.c` |
| `cp -r` | `-r` = **r**ecursive（递归） | 复制整个文件夹（把里面每层一起拷走） | `cp -r dir1 dir2` |
| `mv` | **M**o**v**e | **移动**文件；如果在同一目录下移动，就是**改名** | `mv old.c new.c`（改名）<br>`mv a.c ./src/`（移动） |
| `rm` | **R**e**m**ove | 删除单个文件（**没有回收站**） | `rm a.c` |
| `rm -r` | `-r` = **r**ecursive（递归） | 删除文件夹及里面所有内容 | `rm -r test` |
| `rm -rf` | `-f` = **f**orce（强制） | **不询问、强行永久删除**整个文件夹（慎用） | `rm -rf test` |
| `rmdir` | **R**e**m**ove **Dir**ectory | 只删**空文件夹**（里面有东西就拒绝删，很安全） | `rmdir test` |

> **避坑提醒**：删文件夹前，先看清楚自己是不是正站在它里面。比如提示符显示 `~/c/test$` 时，必须先 `cd ..` 退出来，才能 `rm -r test`。

## 四、看内容、装软件、查帮助（5 个基础命令）

| 命令 / 参数 | 英文原意 | 作用 | 常用示例 |
| --- | --- | --- | --- |
| `cat` | Con**cat**enate（连接输出） | 一口气把小文件的内容打印到屏幕上 | `cat hello.c` |
| `clear` | **Clear**（清除） | 清空满屏历史输出，让终端变干净 | `clear` |
| `sudo` | **S**uper**U**ser **Do** | 临时借用管理员（root）权限执行这条命令 | `sudo apt update` |
| `apt` | **A**dvanced **P**ackage **T**ool | Ubuntu 的软件商店命令行工具 | 见下面两行 |
| `apt update` | **update**（更新列表） | 刷新软件商店的最新目录清单（装软件前先跑） | `sudo apt update` |
| `apt install -y` | **install**（安装）<br>`-y` = **y**es（全选同意） | 安装软件，遇到“是否继续 [Y/n]”自动填 Yes | `sudo apt install build-essential -y` |
| `man` / `--help` | **Man**ual（手册） / **Help**（帮助） | 忘了某个参数啥意思，直接查官方说明（`man` 按 `q` 退出） | `mkdir --help` 或 `man ls` |

## 五、写代码与编译 C 语言（只记这一套就够用）

### 1. 用 `vim` 改文件（只记 6 个按键字母）

`vim` = **Vi** I**m**proved（终端里的文本编辑器），打开命令：`vim hello.c`

| 按键 / 指令 | 英文原意 | 作用 |
| --- | --- | --- |
| `i` | **i**nsert（插入） | 进入打字模式，此时才能正常写代码 |
| `Esc` | **Esc**ape（退出） | 写完代码后按它，退出打字模式回到命令模式 |
| `:w` | **w**rite（写入） | 保存文件 |
| `:q` | **q**uit（退出） | 退出 Vim |
| `:wq` | **w**rite + **q**uit | **保存并退出**（最常用，敲完按回车） |
| `:q!` | `!` = 强制 | **不保存、强制退出**（改乱了想重来时用） |

### 2. 用 `gcc` 编译并运行

`gcc` = **G**NU **C**ompiler **C**ollection（C 语言编译器）

```bash
gcc -Wall -g hello.c -o hello && ./hello
```

把这一句里的每个字母拆开看：

| 写法 | 英文原意 | 作用 |
| --- | --- | --- |
| `-Wall` | **W**arnings **all**（全部警告） | 让编译器把代码里容易出 Bug 的隐患提醒你 |
| `-g` | debu**g**（调试） | 把调试信息塞进程序，以后查错用得上 |
| `-o hello` | `-o` = **o**utput（输出） | 给生成的可执行文件起名叫 `hello`（**千万别把 `-o` 后面写成源码名 `hello.c`，会覆盖源码**） |
| `&&` | **AND**（并且） | 前面编译成功，紧接着自动运行后面的程序 |
| `./hello` | `.`（当前目录）`/`（下的）`hello` | 运行刚编译出来的 `hello` 程序 |

## 六、终端 5 个救命快捷键

| 按键 | 英文原意 / 记忆法 | 作用 |
| --- | --- | --- |
| `Tab` | 自动补全键 | 敲完命令或文件名的前两个字母按它，系统帮你把剩下全补齐（**最高频按键**） |
| `↑` / `↓` | 方向键上下 | 翻找刚才敲过的命令，不用重新手打 |
| `Ctrl + C` | **C**ancel（取消） | 程序死循环或终端卡住时，按它立刻强行中止 |
| `Ctrl + L` | 记作 C**l**ear | 一键清屏（等同于敲 `clear`） |
| `Ctrl + D` | End of input / Exit | 关闭当前终端窗口或退出交互环境 |
