# 如何在电脑上建立一个测试后端？

最近在搞组件，我想黑盒一下fetch和post标准请求，让语句简单一点。
然后呢，我发现我并没有后端测试，为了实现一个完美的测试，我要新建一个简单的后端测试接口，那么这里我又可以写一篇教学了。

## 1. 准备工作：创建项目

直接回到你的电脑桌面，新建一个文件夹，命名为 `tukuai-server`。这就是我们后端服务器的大本营。

## 2. 扫清障碍：解除终端权限拦截

在 Windows 系统下，PowerShell 默认的安全机制（执行策略）很可能会拦截我们的脚本运行。为了不让它拦路，我们需要执行一行“一劳永逸”的代码。

打开刚才新建的文件夹，**按住键盘上的 `Shift` 键，在空白处点击鼠标右键**，选择“在此处打开 PowerShell 窗口”或“在终端中打开”，然后输入并回车运行以下命令：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

```

## 3. 核心步骤：安装框架与依赖

一个现代化的极简后端，离不开两大神器：

* **`express`**：最经典、最轻量的 Node.js 后端框架。
* **`cors`**：跨域神器。如果没有它，你的前端 HTML 请求后端时会被浏览器无情拦截；它也是很多新手最容易漏装导致启动报 `Cannot find module 'cors'` 错误的元凶。

在终端中依次运行以下两行命令，初始化项目并把这两个依赖装好：

```powershell
npm init -y
npm install express cors

```

## 4. 注入灵魂：编写服务端代码

在 `tukuai-server` 文件夹里新建一个文本文件，重命名为 `server.js`（注意后缀是 `.js`）。用任意代码编辑器（或记事本）打开它，复制并粘贴下面这段极简代码：

```javascript
// ==========================================
// TuKuai 微型后端 (server.js)
// ==========================================
const express = require('express');
const cors = require('cors');
const app = express();

// 让后端允许跨域，并自动解析前端发来的 JSON (这就相当于后端拆包裹的黑盒)
app.use(cors());
app.use(express.json());

// 模拟一个数据库 (存放在内存里的数组)
let tukuaiDatabase = [
    { id: 1, title: "系统留言", body: "少侠，欢迎连接到你自己的后端服务器！" }
];

// 【接口 1：响应 GET 请求】前端来要数据
app.get('/api/posts', (req, res) => {
    console.log("🚚 收到前端的 GET 请求，正在下发数据...");
    res.json(tukuaiDatabase); // 把整个数据库打包发给前端
});

// 【接口 2：响应 POST 请求】前端来交数据
app.post('/api/posts', (req, res) => {
    console.log("🚚 收到前端发来的 POST 包裹：", req.body);
    
    // 把前端发来的数据加上一个新 ID，存进我们的“数据库”
    const newPost = {
        id: tukuaiDatabase.length + 1,
        title: req.body.title,
        body: req.body.body
    };
    tukuaiDatabase.push(newPost); // 真实保存！
    
    // 给前端发回执，告诉它状态是 201 (创建成功)
    res.status(201).json({ success: true, message: "后端已入库！", data: newPost });
});

// 启动服务器
app.listen(3000, () => {
    console.log("🚀 TuKuai 后端已启动！监听端口 3000...");
    console.log("测试地址: http://localhost:3000/api/posts");
});

```

## 5. 点火发射：运行你的服务器

回到刚才的终端窗口，输入启动命令：

```powershell
node server.js

```

## 6. 见证奇迹

如果一切顺利，你的终端里会打印出这样的画面：

```powershell
PS C:\Users\TuKuai\Desktop\tukuai-server> node server.js
🚀 TuKuai 后端已启动！监听端口 3000...
测试地址: http://localhost:3000/api/posts

```


这样你就拥有一个真实的后端本地接口啦！但是！因为这个变量只存在于运行这段代码的那个 Node.js 进程的**系统内存**里，它面临着一个残酷的现实： **一旦你把黑底白字的 PowerShell 终端关掉，或者在终端里按了 `Ctrl+C` 停止了服务器进程，这块内存就会被操作系统立刻回收清空。**
仅仅是做一个测试，注意力还是放在前端请求上，为了不让前端请求小姐姐总是打出KuaiFetch驼峰大忌，又为了极简准备这次就叫kf。
