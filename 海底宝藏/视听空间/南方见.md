# 南方见

<tukuai-player url="media/videos/南方见.mp4" title="南方见"></tukuai-player>


一段朴实而触动人心的告别短片。我愿称之为艺术。



**英文翻译 (English Transcript):**


"I'm off, heading out to work now. **See you down South. The South. See you in the South.**

I won't have time to reply to each of you individually, really sorry about that. Because I'm leaving now, going off to work, so I don't have the time to get back to everyone one by one. **Hope you all understand.**"



**中文原话：**


“走了，打工去了。**南方见。南方。南方见。**

没有时间一一给你们回了啊，不好意思啊。因为我走了，打工去了，没有时间给你们一一回，**大家理解啊。**”
