# 💯网页图标全端适配与规范指南

**浏览器标签页、Google 搜索结果和手机主屏幕会分别挑选图标。** 标签页可以用 SVG，同时提供 PNG 和 ICO 以兼容更多浏览器。一张 96×96 的正方形 PNG 就能满足 Google 自然搜索对图标格式和尺寸的要求。iPhone 主屏幕图标用 `apple-touch-icon` 声明，Android 安装应用时用到的图标写进应用清单。

## 一、可复制的网页与清单配置

下面的例子假设首页在域名根目录 `/`，图标和清单也放在这一层。把这几行放进全站页面模板的 `<head>`，让首页和文章页都能读到。

```html
<!-- 标签页图标。ICO 文件内含 32×32 位图 -->
<link rel="icon" href="/favicon.ico" sizes="32x32">
<link rel="icon" href="/favicon-96x96.png" type="image/png" sizes="96x96">
<link rel="icon" href="/favicon.svg" type="image/svg+xml" sizes="any">

<!-- iPhone 和 iPad 添加到主屏幕时使用的图标 -->
<link rel="apple-touch-icon" href="/apple-touch-icon.png" sizes="180x180">

<!-- 应用清单，记录启动地址和安装图标 -->
<link rel="manifest" href="/site.webmanifest">
```

将以下 JSON 保存为 `site.webmanifest`，把名称换成自己的站名。`start_url` 填用户点开已安装应用时要进入的页面。

```json
{
  "name": "站点名称",
  "short_name": "简称",
  "start_url": "/",
  "icons": [
    { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ],
  "theme_color": "#ffffff",
  "background_color": "#ffffff",
  "display": "standalone"
}
```

> **移动图标时，检查两处路径。** 网页用 `href` 找图标和清单，清单用 `icons[].src` 找安装图标。例如把 `icon-192.png` 移进 `/favicon/`，就要把它的 `src` 改成 `/favicon/icon-192.png`。如果整个应用部署在 `/docs/` 下，首页是 `/docs/`，就把 `start_url` 写成 `/docs/`，资源路径也按实际位置填写。以 `/` 开头的路径总是从域名根目录算起。清单里的 `./icon-192.png` 则指向清单所在目录。

## 二、各端怎样选择图标

### 1. 浏览器标签页与深浅色主题

SVG 用线条和形状描述图案，适合在不同像素密度的屏幕上显示同一个标志。`sizes="any"` 告诉浏览器这张图可以缩放。有多个 `rel="icon"` 时，浏览器会按格式、尺寸和媒体条件挑选。**只有多个候选同样合适时，才选最后声明的那个。** 因此模板把 SVG 放在这三项的最后。

Safari 从 26.0 开始支持 SVG 网页图标。WebKit 也确认过，macOS Safari 26.3 能显示 SVG 图标，却会忽略图标内部的深色模式设置。因此，先让图案和它自己的底色有足够对比，再用 `prefers-color-scheme` 为支持它的浏览器换色。

下面是一个可以直接保存为 `favicon.svg` 的例子。默认是深底白菱形，支持深色偏好查询时可以换成浅底深菱形。即使只显示默认配色，也能看清菱形。

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64">
  <style>
    .tile { fill: #1e293b; }
    .mark { fill: #ffffff; }
    @media (prefers-color-scheme: dark) {
      .tile { fill: #e2e8f0; }
      .mark { fill: #0f172a; }
    }
  </style>
  <rect class="tile" x="2" y="2" width="60" height="60" rx="12"/>
  <path class="mark" d="M32 12 52 32 32 52 12 32Z"/>
</svg>
```

部署后检查图标请求是否返回 SVG 文件，并将服务器响应头设为 `Content-Type: image/svg+xml`。有些站点会把不存在的路径也转到首页，这时即使看到状态码 200，返回的也可能是 HTML。

### 2. 根目录的 ICO 有什么用

一个 ICO 文件可以包含多张位图，常见做法是打包 16×16、32×32 和 48×48 三种尺寸。模板写 `sizes="32x32"`，表示文件里确实有这个尺寸。Evil Martians 曾用这个写法处理特定 Chrome 版本的图标选择和重复下载问题。它可以作为兼容写法，实际选中哪张、请求几次，仍取决于浏览器。

如果网页没有声明 `rel="icon"`，浏览器可以尝试读取域名根目录的 `/favicon.ico`。把 ICO 放在这里，能照顾沿用这个约定的客户端。如果你只管理 `/docs/` 这样的子目录，也可以在自己的网页里显式引用 `/docs/favicon.ico`。

### 3. Google 自然搜索结果

在**主机名首页**的 `<head>` 中声明图标。模板里的 `rel="icon"` 就可用于这一步。Google 也接受 `shortcut icon`、`apple-touch-icon` 和 `apple-touch-icon-precomposed`。

| 要检查的项目 | Google 的规则与本文的做法 |
|---|---|
| 文件格式 | 官方列出 BMP、GIF、ICO、PNG、JPEG、PPM、TIFF，列表中没有 SVG。可以使用模板里的 96×96 PNG。 |
| 比例与尺寸 | 图标须为正方形，至少 8×8 像素。官方建议大于 48×48 像素。 |
| 站点范围 | 每个主机名支持一个图标。`example.com` 和 `news.example.com` 可分别设置，`example.com/news/` 与同一主机名的其他页面共用。 |
| 抓取权限 | `Googlebot` 要能访问首页，并跟随首页的重定向到达声明图标的页面。`Googlebot-Image` 要能抓取图标文件。检查 `robots.txt` 和访问权限。 |
| 更新与展示 | 图标地址应保持稳定。修改后，Google 重新抓取可能需要几天到几周，最终是否展示由 Google 决定。 |

这些规则适用于 Google 自然搜索。至于 Bing、百度等其他搜索引擎，是否尝试读取根目录 ICO，应以各自公布的规则为准。

### 4. 手机主屏幕、应用安装与媒体封面

- **iPhone / iPad 主屏幕。** 可以准备一张 180×180 的正方形 PNG，通过 `apple-touch-icon` 声明。背景铺满整张图，圆角交给系统裁切。部分 iOS 环境出现过透明区域显示黑边的情况，使用不透明底色更容易保持预期外观。
- **Android 与渐进式网页应用（PWA）。** 在清单中提供 192×192 和 512×512 两张 PNG，供系统按场景选择。如果希望 Chrome 主动显示安装入口，清单应包含名称、启动地址、图标和合适的显示模式。浏览器还会检查 HTTPS、用户使用情况等条件。
- **让 Android 裁图时保住标志。** 可以另做一张 512×512 的 PNG，在它的清单条目中加上 `"purpose": "maskable"`。背景铺满画布，重要图案放进以画布中心为圆心、直径为图标边长 80% 的圆内。这样系统套上圆形或圆角遮罩时，主体仍然完整。
- **锁屏、控制中心与灵动岛的媒体封面。** 有播放器的网站可以通过 Media Session API 的 `MediaMetadata.artwork` 提供当前歌曲或视频的封面。具体界面是否显示、采用哪张，由浏览器和系统决定。站长曾在 iOS 上看到缺少封面时显示了 `apple-touch-icon`。如果希望用户认出正在播放的专辑，应为这张专辑单独提供封面。

## 三、文件清单

| 示例文件 | 格式与尺寸 | 用途 |
|---|---|---|
| `/favicon.ico` | ICO，内含 16×16、32×32、48×48 位图 | 兼容旧客户端，也可供浏览器按根目录约定查找 |
| `/favicon-96x96.png` | 96×96 PNG | 浏览器可选的位图，也符合 Google 自然搜索的格式与尺寸要求 |
| `/favicon.svg` | 矢量 SVG | 标签页图标，支持的浏览器可随深浅色偏好换色 |
| `/apple-touch-icon.png` | 180×180 实底 PNG | iPhone 和 iPad 主屏幕图标 |
| `/icon-192.png`、`/icon-512.png` | 192×192、512×512 PNG | 供系统按所需尺寸选择应用图标 |
| `/icon-maskable-512.png`（可选） | 512×512 实底 PNG | 另加到清单，并标为 `maskable`，供系统按设备形状裁切 |
| `/site.webmanifest` | JSON 清单 | 记录应用名称、启动地址和安装图标路径 |
